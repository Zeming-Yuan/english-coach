# 全站视觉基准：沿用已确认的故事页

2026-11-02，用户反馈整套新稿的颜色与质感仍不满意，并明确要求颜色、质感按照已确认的故事页处理。本决定替代之前的灰青色方向；蓝白、亮橙探索稿不作为后续实施目标。

## 唯一风格来源

- 已确认原稿：`../story-reader/reference.png`。
- 已有实现 token：`frontend/src/views/story-reader.css` 中 `.app.story-workspace`。
- 继承颜色、表面、英文内容排版、图标线条、按钮与导航质感。各页面按本身任务组织内容，不复制故事正文与查词栏布局。

## 必须一致的视觉规则

| 用途 | 颜色 |
|---|---|
| 内容底色 | `#FCFAF6` 暖白 |
| 导航底色 | `#F1EEE8` 暖灰 |
| 主文字、主要按钮 | `#302E2B` 炭黑 |
| 次要文字 | `#736C63` 暖灰褐 |
| 分隔线 | `#E5DFD5` |
| 强调色 | `#A26243` 陶土 |
| 内容高亮 | `#F0E4D7` |
| 导航选中底色 | `#E6E0D7` |

- 主按钮采用炭黑底与暖白字，圆角约 6px；陶土色用于少量链接、选中图标和内容引用线。
- 中文界面使用 Noto Sans SC 或现有中文无衬线字体；英文学习内容使用 Tinos。中文标题不统一替换成宋体。
- 保留纸面般的暖白与留白；优先通过对齐、间距和字重区分信息。不要新增噪点贴图、光晕、玻璃模糊或装饰渐变。
- 图标继承故事页的 Phosphor 线条体系。
- 列表、课程、设置仍按各自功能组织；专注练习仍保留其专注模式，不为统一风格强加侧栏。

## 评审和落实

用户随后明确确认第三张词条详情图，并要求其他页面同样采用。该图成为全站颜色、表面和控件的视觉基准；不是要求所有页面复制词条两栏布局。

已完成对应前端实现。实际截图、逐页巡检和验证结果见 `../story-family-implementation/README.md`。后续修改仍需逐页对照参考与浏览器截图，不能仅凭 token 名称相同宣布视觉一致。
