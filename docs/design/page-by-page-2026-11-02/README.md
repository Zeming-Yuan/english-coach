## 使用边界

- 这些是桌面静态视觉稿及代表性状态，不能替代交互、移动端、深色模式及所有异常路径的验收。
- 新稿中的课程、故事、词典释义和学习记录属于示例内容；落地时使用真实数据，不新增未经确认的产品能力。
- 首页练习入口仍应遵循现有练习请求语义，不能暗示已自动绑定某篇故事或课程。
- 个别图片的导航文字、字体和间距仍有生成漂移；实现前须统一设计 token 和导航标签。
- 建议练习图展示创建失败；回测图展示间隔未达到。其他状态沿用实际原因和既有行为。
- 已确认故事阅读页保留原稿，其他页面尚未获视觉确认；本轮没有修改前端产品代码。
