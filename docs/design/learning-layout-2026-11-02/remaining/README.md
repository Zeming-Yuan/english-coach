## 统一设计

沿用已认可首页的暖白内容面、暖灰导航、炭黑文字、细分隔线和少量陶土色。内容型页面提高可扫描密度，以实际词汇、摘要、记录和操作补足信息；练习型页面保持单题焦点，缩短题目、输入与操作之间的距离，不靠泄露答案或添加无关统计填空间。

- 单词本：词形、中文释义、回忆依据和朗读对齐到固定列；减少每个字母分组造成的过大空隙。
- 词条详情：释义与例句是主内容，记忆法就近编辑；学习依据单独分栏，避免重复展示技术元数据。
- 故事库：补齐中文摘要、版本和检查入口；沿用原版/简化版的实际关联，不把同一故事复制成无关推荐。
- 加词：输入、数量和生成动作紧邻；入门词卡是次级入口。生成失败应保留输入。
- 学习记录：概况、最近七天、回忆证据和延迟保持分组，不合并成“掌握率”。
- 设置：标签、说明和控件按行对齐，学习、外观、维护和备份分节。
- 备份：下载与恢复分开，替换前先核对影响；V1部分恢复与V3全量替换仍须使用不同说明。
- 练习与短测：统一题干、作答区、提示和操作的层级；题型、帮助、保存状态和返回入口清楚可见。

## 功能核对与落地约束

已阅读相关现有页面及 ADR-0005、0006、0007。图稿附带真实页面截图和已认可首页作参考，未重新调研或引入外部产品功能。

1. 听写当前是听音四选一，选择后直接确认保存；不凭设计稿新增输入式听写。
2. 测验选择题是中文题干、英文选项；选中与确认保存分开。读后理解题仍按现有冻结材料显示，不硬编码图中的中文示例题。
3. 词汇回忆状态使用已有五类证据标签；课程生成、打开、浏览、检查不替代词卡回忆依据。
4. 猜词、拼写、课程输入题和读后词汇题不能在未请求帮助前暴露目标英文、音标或答案长度；音频、选项和答案的实际接触记录保持原机制。
5. 提示只增不减。若显示首字母，已按辅助作答处理；不能用可取消的勾选来清除帮助。保存失败保留原题、输入、帮助及提交身份，继续确认原请求，不另开一轮。
6. 词条图中的“最近活动”仅能绑定实际可读取的事件；缺少接口或数据时收起，不因效果图增加伪造的生成/加入记录。回忆样本、时间、排期和所有图表数据均来自真实响应。
7. 生成图中的字号、音标、日期、分数和控件不是数据规范。实现必须使用现有中文 Noto Sans SC 与英文 Tinos、本地化格式和服务端计算结果，不抄写图片里的示例值。
8. 若图稿里的练习页面带侧栏或错误高亮了课程/单词本，实现仍沿用既有专注模式隐藏全局导航。图片仅用于题干与操作区的视觉参考；导航归属按真实入口，不更改路由行为。
9. 主按钮默认炭黑；陶土色只作少量强调和替换风险提示。部分生成图扩大了陶土色按钮、字级或边框，实现时按已确认首页统一校准。
10. 空词库、单课、无对话、无故事、无证据、加载失败与重试都要有自然收缩的布局；不能为撑满页面自动生成内容或写入用户数据。

## 范围与验收

本轮覆盖主要页面和代表状态；没有声称逐一覆盖所有弹窗、深色模式、移动端及全部错误分支。原版/简化版阅读、查词弹层继续沿用已认可故事页；读后检查新增了配套图。学习结果图展示主轮、巩固及不同证据类别，实际排期不能从自评次数推算。

落地后的最高浏览器验收入口仍为首页开始/继续学习，经实际内容操作进入练习，提交确认后回到结果与学习记录；另覆盖课程打开→短测、故事阅读→版本切换→读后检查、备份选择→预览→取消/确认等已有路径。实施时重新截图并与本轮参考同尺寸并排检查，不能以旧测试通过代替视觉验收。

本轮无产品代码变更，无数据库写入，无提交、推送或外部发布。图册仅检查文件完整性和页数，未宣称功能测试通过。原始提示词与来源见 briefs.json 和 manifest.json。
