## 排版变化

- 首页：将本轮词卡、最低目标与主要动作合成一条紧凑区域；当前课程展示目标、词义和对话场景；故事展示摘要；专项练习放在下方，减少首屏重复统计。
- 课程目录：用有内容的课程提纲替代薄列表；一行能看清学习目标、词汇/对话数量和预览；右侧提供所选课程内容，减少空白状态旁栏。
- 课程学习：词汇与对话按适当行宽组织，缩短猜词输入框；用清楚的阶段区分猜词、阅读与短测；保留浏览、生成与检查结果的语义差异。

## 样例数据与真实边界

图稿中的三课、六词和四句对话是排版样例，不代表用户当前数据。原预览 fixture 只有一课、一个词、没有对话；不能仅用这个稀疏状态判断完整课程的排版。没有向用户数据库写入样例。

目录 API 已提供课程 content，可从实际 words/dialogue/tips 派生内容摘要；学习目标只能使用真实内容里的目标或提示，缺失时不编造。课程只存在一课、没有对话或故事时，应自然收缩相应区域并提供现有入口，不能填假课程或用多个空状态框占位。

## 实现前需校准的交互细节

1. 目录生成图中第3课同时标为未打开和继续第3课；实际实现必须按状态使用开始或继续，不照抄这个矛盾。继续已存在课程调用打开流程；生成第4课才调用生成流程。
2. 猜词状态必须保留输入后揭晓的操作；不能因为并排阅读对话而把预测试当作未接触证据。目标词、释义和音频实际接触的记录行为必须保留，必要时分阶段展示阅读区域。截图中隐藏词义并不证明没有其他答案提示。
3. 生成图中文字、音标、字号与字体不是内容或排版真值。实际界面仍采用已有 Noto Sans SC 与 Tinos，读取课程真实数据；保留键盘提交、朗读、词汇揭晓、短测与保存失败重试。
4. 内容已看完只记录浏览；生成课数、打开课数、浏览课数均不表示掌握。短测证据单独呈现。

## 后续落地验收入口

- 首先用完整课程样例验证首页 → 打开已有课程 → 猜词/揭晓 → 阅读/朗读 → 本课短测的用户路径。
- 单独验证零课、单课、无对话、无故事、加载失败与生成失败；不得自动生成课程或写入用户数据来填版面。
- 桌面和窄屏实拍，检查行宽、文字换行、操作顺序和横向溢出；窄屏按学习顺序堆叠，不能简单压缩两列。
- 功能验证沿用相关 Playwright 入口，视觉验收必须使用本轮实现后的新截图。上一轮功能通过不等于本轮布局已被认可。
