# 前端改版：合并范围与行为

用户已选择首页方案 1，并授权将前端改版提交 PR、无冲突且检查通过后合并到 dev。

## 目标与范围

面向个人或小范围英语学习用户，用故事阅读页认可的暖色阅读质感统一现有页面。首页减少同色留白，明确每日学习、课程、故事和专项练习的主次；拼写界面借鉴 Qwerty Learner 的排字与输入反馈，但继续使用本项目独立/辅助作答与保存语义。

- 桌面采用统一侧栏，手机保留可达导航；今天、课程、单词本、故事、学习记录及设置等现有页面沿用相同字体、色彩与控件体系。
- 首页按 [选定方案](home-contrast-2026-11-02/option-1.png) 实现深色任务区、课程/故事双栏与四种专项练习分组。统计、建议、错词复习和回测入口保留。目标与冻结轮次不互相替代。
- 课程/故事/推荐词读取既有 API，分别处理加载、失败与重试；可选内容故障不得阻挡每日学习与场景入口。无课程/故事/词卡时显示真实空状态。
- 首页课程和故事只提供保守中文预览。缺少中文或含英文目标词时使用中文概述/占位，不提前显示独立作答答案，不自动写打开、接触、学习完成或成绩。
- 故事页保留中英显示、查词、原句与朗读；英文朗读按现有接口限制正规化标点并分段，不丢词。
- 单词详情沿用现有编辑、学习证据与历史功能，调整层次和布局，不推导掌握百分比。
- 拼写独立模式不显示长度、首字母、音标或逐字正确性；明确请求辅助后才显示相应反馈，帮助记录不可通过切回独立模式清除。保存成功后才显示已保存与更新计数；IME Enter不得提前提交，失败保留输入并可重试，减少动态效果偏好生效。
- 保留原有课程、故事、建议练习、回测、场景和恢复流程，不更改 API、数据库或持久化规则。

## 来源与资产

界面图标使用 Phosphor，UI 使用项目 Noto Sans SC，英文阅读使用 Tinos。字体许可证随包分发于 app/static/fonts。故事配图为独立生成资产。Qwerty Learner仅作为交互参考，本次未复制其源码。

## 明确不做

不发布演示样例到用户数据库，不伪造连续天数/进度/学习证据，不加入新收费、认证或外部消息功能。用户原目录独立的许可证与商业文档不在本 PR 中。不把生成图当可交互实现，也不把局部用例通过声称为全站验收。

## 验证入口

- 前端构建：`npm --prefix frontend run build`；提交相应产物，使原有 FastAPI 静态入口可直接使用。
- 前端工具：`node --test frontend/src/lib/*.test.mjs`。
- 后端：`.venv/bin/python -m pytest -q`。
- 浏览器：现有 e2e/playwright.config.mjs 双视口；新增 Home 和 Qwerty 用例，保留并更新每日轮次流程的实际按钮定位。
- 审查固定点为本次 PR 的实际 dev 基础；Standards 和 Spec 分别在独立上下文审查整个最终差异。
