## 这次看错了什么

上一版主要替换了底色、字体、边框和导航，仍然沿用旧首页“数字 → 开始按钮 → 统计 → 折叠入口”的组织方式。阅读器的暖底、衬线品牌和宽松比例被当作全站模板，造成工作页面空旷、操作层级弱。控件统一解决不了内容组织问题。

## 新的分工

- 全局工作区：Linear 的克制导航，加 Fluent 2 式的正常控件尺度。中性灰白、单一克制蓝色，中文无衬线字体；16–18px 图标、约36px导航行、约52px工具栏作为新稿目标。
- 首页：明确的一轮学习任务，其下是可继续的课程和专项练习。数字是任务的说明，不是页面主角。
- 课程/故事/词库：参考 Readwise 的列表与详情分工。Apple Books 的内容身份只在内容库里使用。
- 练习：参考 Enjoy 的单任务聚焦与底部操作区；独立作答不提前显示英文、音标或长度，提交确认前不前进。
- 故事阅读：保留已认可的独立阅读主题。它是产品中的阅读模式，不是所有页面的通用布局。

新稿为同一产品系统里的首页、课程库和独立练习三张具体页面。先评估结构和任务层级，再落地全部路由；不再把换色当作全站重构完成。
