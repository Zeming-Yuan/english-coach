仅返回同课程最近未结束轮次的身份，稳定按创建时间/保存序号排序；查询不写学习或推进状态。

显式新开与薄弱练习保留原语义。旧轮次仍按原修订检查并保留首答/提示，未新增持久用途或备份集合。

外部 AI 夹具为毕业句卡请求提供可选独立响应，避免后台请求竞争消耗课程/故事材料。
只分派外部客户端响应，不替换生产 API、事务或后台函数；未配置该响应的旧测试仍严格按队列消费，耗尽失败。
