# ADR-0008：限定三轮场景与独立应用证据

- 状态：已采纳
- 日期：2026-11-02
- 票据：EL-14 / #50

场景复用持久练习轮次，但任务不是词卡评分。买饮品固定请求水、表达一杯、确认并致谢三个任务；随应用分发经人工核对的中文角色模板、完整句式、槽位和拒绝集合。完整匹配才认可，显式不满足才拒绝，其他表达未判定；空答案继续输入，显式跳过单列。规则版本、内容修订及摘要随轮次冻结，不调用 AI 判分。

`scene_attempts` 只追加真实提交，题目引用唯一首答 UUID；新标识再次作答保存为辅助再练，不覆盖首答。三题首答全部认可且无帮助才独立通过，其他三题已处理仅表示流程完成。请求提示或标准表达先保存只增不减的帮助，再返回内容；准备页仅展示中文释义、准备状态与缺词数量，避免提前回显可直接作答的词形；标准表达实际展示及实际开始朗读通过既有接触接口分别记录 source=scene 的可见/音频接触，失败保留原接触身份供确认，语音失败不撤销保存。

创建、原标识回放、作答及完成生命周期均在既有 `run_write` 的 BEGIN IMMEDIATE 内确认。缓存响应先于规则/词卡失效检查，同标识异内容 409；提交标识跨词卡与场景使用同样冲突。无效输入 422，缺失目标 404，修订或规则变化 409。多任务共享的任一目标变化后整轮停止新作答，保留原答案和历史读取；不悄悄换目标。

应用维度只读取当前词卡身份/修订上的任务首答。成功需三题独立通过，且该任务明确映射到此目标，答案不照抄已存例句、存量教学例句也没有命中同一任务模板。保存词卡例句、课程例句/对话的教学快照和限定情境 `drinks:water-order` 作为依据；这只验证固定任务，不推断其他场景、口语或全部词汇能力。未知、跳过、帮助、再练不生成独立成功；独立明确失败只降低相应目标的应用维度，回忆与保持不改写。超过 30 天显示历史应用证据。

场景记录不生成 ReviewEvent，不调用 FSRS，不计入词卡完成量、客观输入正确率或连续学习日。PracticeItem 的词卡关联为场景任务留空；目标映射引用稳定业务身份与修订，无本地整数 ID。删除词卡不会级联删掉场景历史。

V3 当票登记全部场景数据，强类型校验用途、三个任务、规则快照、目标映射、首答/再练引用、业务指纹和缓存结果。恢复保留 UUID 与规则身份，词卡整数 ID 沿既有恢复分配器重映射，不重新判分或排期。早期 V3/V2/V1 缺少场景记录时明确标注未记录，不补造能力；已删除目标作为历史身份保留。今后新增规则版本必须保留旧规则材料及兼容校验，不能覆盖旧文件后丢弃恢复能力。

功能回退使用 `SCENES_ENABLED=false` 并重启：关闭新场景启动，保留原创建确认、已存轮次读取/作答、V3 导出恢复，应用摘要显示历史说明。恢复 true 可逆开启。迁移只扩展并保留所有数据；降级拒绝删除新表，不用旧快照覆盖新学习。

## EL-15：自我介绍与虚构问路

2026-11-03 扩展为三类场景，继续使用同一 Session/SceneAttempt、首答、帮助与事务契约。自我介绍固定 name/origin/preference，姓名与来自地点只填槽位；喜好限定喜欢茶，目标为 tea。问路固定 destination/direction/confirmation，仅在虚构广场到车站、路口左转的情境中判定，分别映射 station/left/thank。不将此结果外推为真实导航、专名拼写、口语或综合英语能力。

准备状态、角色称谓、继续/新开轮次及应用证据都按场景选择；V3 严格验证各场景的冻结材料和情境映射，继续保留原买饮品规则及旧备份兼容。新增材料的人工核对记录见 app/data/README.md。独立通过只说明实际三个任务；没有目标映射或照抄教学材料时，仍显示迁移能力尚未验证。

应用摘要按场景情境、规则版本和内容摘要分别计算并展示，失败只影响同一情境的对应版本；不同情境的通过保持独立。词卡总览表示至少一个指定情境存在证据，详情列出每个情境的结论，不把所有情境混成一次成绩。
