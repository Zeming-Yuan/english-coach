# ADR-0007：有边界的故事材料与生成事务

- 状态：已采纳
- 日期：2026-11-02
- 票据：EL-11 / #47

## 背景

旧生成器使用未复习新词，不校验可读难度或保存理解题上下文。生成数量不能表示学习效果；旧内容也不能自动获得新题和成绩。

## 决策

1. 个人已知只使用 EL-02 当前内容修订上 `verified` 的独立回忆依据。按稳定顺序选一至三个单词词形；显式同意时可额外选一个尚未有有效依据的词库目标。不以自评、识别、辅助或旧基线补齐已知。生成不创建词卡、不写学习事件、不改变排期。
2. `support_words.json` 是有版本的教学支撑材料，不表示个人掌握。词形统一小写、保留词内撇号；不隐式词形还原。标准正文 40–70 词，每个英文句子最多 12 词；标题、正文、题干与选项的不同未覆盖词形合计最多两个。中文配对、全部目标出现、三选项、唯一可定位答案及证据句均由确定规则校验。词形覆盖不保证理解全文。
3. 缺少合适个人依据时返回已核对入门材料，保持词库不变，不保存为个人生成结果。入门材料固定版本，旧故事保持原文可读并显示暂无检查题；本票不开放读后评分。
4. 外部调用不持数据库锁。非法材料最多修正一次；失败返回明确错误，原故事不变。保存前在 `BEGIN IMMEDIATE` 内先查操作重放，再复核内容身份/修订与全部覆盖依据。恢复改变内部修订行身份，即使保留业务身份也使原请求失效。保存故事、关联与 `StoryVersion` 同事务提交。
5. `StoryVersion` 是不可变的已校验材料快照：独立版本 UUID、生成操作 UUID、同意选项、故事身份/修订、双语原文、完整题干/选项/答案/证据句和当时覆盖说明。同操作同选项回放原结果，不再次调用 AI；改选项 409。删除故事解除版本的活故事引用，保留版本墓碑，原操作返回 410，不复活内容。词卡删除只移除现有 StoryWord，历史版本原文保持可读。
6. `story_versions` 当票登记 V3：强类型与唯一身份校验、活故事引用和原文对应校验、材料质量重验、story_id 映射、导出和原子恢复。墓碑没有活故事引用。V2/早期 V3 缺集合时明确说明无故事版本及题目材料；不补造题目或成绩。
7. 浏览器在 `ec.story-generation` 保留待确认操作与选项。保存或网络失败后可继续确认，刷新仍使用原操作；本地存储失败说明仅内存保留。生成结果不自动改变阅读选择；详情读取以选择序号丢弃晚到响应；删除当前待打开故事也使在途读取失效；若详情已在删除确认前打开，确认成功只关闭对应故事，保留其他当前选择。
8. `BOUNDED_STORIES_ENABLED=false` 隐藏并关闭新生成入口，GET 故事、版本与 V3 读写仍兼容。恢复 true 可逆开启；迁移降级拒绝删除已产生内容，功能回退不靠清库或覆盖旧快照。

## 取舍

版本同时保留内容与覆盖说明，增加存储量，换取可核对的固定题目上下文与重放身份。内容修订围栏偏保守：生成期间无关内容修订也会要求重做，避免恢复前请求落入新数据。删除后的墓碑继续进入备份，以保留不复活的操作语义。

## EL-12 增补：独立简化版本（2026-11-02，#48）

- 简化模式确定限制为 20–40 正文词、所有英文句子最多八词、不同未覆盖词形最多两个。沿用原版全部目标及显式新目标许可、双语和题目校验；不覆盖原版正文，不新增词卡或故事成绩。若原版有效目标依据过期，明确返回 409。
- 每个简化版拥有独立 Story 与 StoryVersion。`mode=short`、`parent_version_id` 引用原版 UUID；原版为 `normal`、无父引用。只有原版可作为简化来源，不建立任意深度版本树。此布局复用现有故事修订/可见目标接触边界，并为后续按版本评分保留独立身份。
- 简化请求携带原版 story_id、version_id 和 operation_id。写事务中先检查操作回放，再检查全部内容修订围栏和回忆依据；同标识不同来源返回 409。生成失败或事务失败不留半个版本。删除任一版仅解除其活故事引用，保留版本墓碑；原版删除后简化版仍独立可读，不能经旧请求复活原版。
- V3 在同一集合显式登记上述字段并映射活故事 ID。UUID 父关联不重写；预览要求 short 只引用同目标/同许可的 normal，拒绝缺失父引用、自引用及环。父版墓碑合法。EL-11 旧字段缺失默认为 normal/null；不存在的故事检查结果继续保持未记录。
- 阅读切换重新建立当前版本的展示观察，不将预取记为接触；接触沿用词卡修订和服务端确认时间，不成为故事成绩。读后检查入口由 EL-13 提供，本票所有版本显示未检查，不迁移自评分或旧成绩。
- 浏览器按原版 UUID 保存待确认简化请求，重复确认沿用 operation_id；导航序号与组件生命周期阻止晚到响应改变已选版本。`SIMPLER_STORIES_ENABLED=false` 独立关闭新简化，兼容读取/切换/V3 保留。只扩展迁移，不提供删除新增数据的 schema 降级。

## 补充：版本与读后结果关联（EL-13 / #49）

`PracticeSession.version_id` 引用不可变故事版本，删除故事后保留版本墓碑与已保存结果；
新作答核对活故事身份/修订，旧题不能继续写入新版本。理解题的冻结上下文必须与该版本
材料完全相符，未校验或证据句不符不发理解题。较早版本缺理解材料时可仅提供真实目标
的输入题，V3 只放宽“材料缺题”，仍重验正文、目标、翻译与覆盖；新生成仍强制完整题目。

`STORY_CHECKS_ENABLED=false` 关闭新轮次创建并隐藏原文旁入口；已有轮次、版本、首答、
帮助和 V3 读写保留。恢复 true 即可重新开启。迁移只扩展现有表并替换题型唯一约束，
拒绝通过 downgrade 删除新增数据；功能回退不覆盖学习快照。

## EL-12 / EL-13 整合

检查与 V3 重验使用各自 `StoryVersion.mode`，原版和简化版都可提供最多两题；
轮次、帮助和首答始终引用各自的版本 UUID，切换不迁移成绩。列表与版本栏按
该版本是否有轮次区分“未检查”和“已有检查记录”，具体成绩仍在读后检查内显示。
版本导航随原文一起隐藏；输入期间回看先保存帮助，确认后才恢复原文与版本导航。

两票迁移保持原 revision 与各自升级路径，用无数据操作的合流节点汇为单一 head；
已升级任一分支的库继续前向升级，保留现有数据和升级前安全副本。
