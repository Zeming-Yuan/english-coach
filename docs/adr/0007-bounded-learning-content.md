# ADR-0007：有边界的故事材料与生成事务

- 状态：已采纳
- 日期：2026-11-02
- 票据：EL-11 / #47

## 背景

旧生成器使用未复习新词，不校验可读难度或保存理解题上下文。生成数量不能表示学习效果；旧内容也不能自动获得新题和成绩。

## 决策

1. 个人已知只使用 EL-02 当前内容修订上 `verified` 的独立回忆依据。按稳定顺序选一至三个单词词形；显式同意时可额外选一个尚未有有效依据的词库目标。不以自评、识别、辅助或旧基线补齐已知。生成不创建词卡、不写学习事件、不改变排期。
2. `support_words.json` 是有版本的教学支撑材料，不表示个人掌握。词形统一小写、保留词内撇号；不隐式词形还原。标准正文 40–70 词，每个英文句子最多 12 词；标题、正文、题干与选项的不同未覆盖词形合计最多两个。中文配对、全部目标出现、三选项、唯一可定位答案及证据句均由确定规则校验。词形覆盖不保证理解全文。
3. 缺少合适个人依据时返回已核对入门材料，保持词库不变，不保存为个人生成结果。入门材料固定版本，旧故事保持原文可读并显示暂无检查题；本票不开放读后评分。
4. 外部调用不持数据库锁。非法材料最多修正一次；失败返回明确错误，原故事不变。保存前在 `BEGIN IMMEDIATE` 内先查操作重放，再复核内容身份/修订与全部覆盖依据。恢复改变内部修订行身份，即使保留业务身份也使原请求失效。保存故事、关联与 `StoryVersion` 同事务提交。
5. `StoryVersion` 是不可变的已校验材料快照：独立版本 UUID、生成操作 UUID、同意选项、故事身份/修订、双语原文、完整题干/选项/答案/证据句和当时覆盖说明。同操作同选项回放原结果，不再次调用 AI；改选项 409。删除故事解除版本的活故事引用，保留版本墓碑，原操作返回 410，不复活内容。词卡删除只移除现有 StoryWord，历史版本原文保持可读。
6. `story_versions` 当票登记 V3：强类型与唯一身份校验、活故事引用和原文对应校验、材料质量重验、story_id 映射、导出和原子恢复。墓碑没有活故事引用。V2/早期 V3 缺集合时明确说明无故事版本及题目材料；不补造题目或成绩。
7. 浏览器在 `ec.story-generation` 保留待确认操作与选项。保存或网络失败后可继续确认，刷新仍使用原操作；本地存储失败说明仅内存保留。生成结果不自动改变阅读选择；详情读取以选择序号丢弃晚到响应；删除当前待打开故事也使在途读取失效。
8. `BOUNDED_STORIES_ENABLED=false` 隐藏并关闭新生成入口，GET 故事、版本与 V3 读写仍兼容。恢复 true 可逆开启；迁移降级拒绝删除已产生内容，功能回退不靠清库或覆盖旧快照。

## 取舍

版本同时保留内容与覆盖说明，增加存储量，换取可核对的固定题目上下文与重放身份。内容修订围栏偏保守：生成期间无关内容修订也会要求重做，避免恢复前请求落入新数据。删除后的墓碑继续进入备份，以保留不复活的操作语义。
