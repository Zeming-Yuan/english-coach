# ADR-0006：课程进度与显式浏览

- 状态：已采纳
- 日期：2026-11-01
- 票据：EL-07（课程有明确目标，生成、浏览和待检查分别记录）

## 背景

课程列表此前把“已生成课程数”显示成“已完成/已学完”，生成即暗示学习完成。课程也没有显式浏览记录，无法区分“生成但未打开”“打开过”“明确看完”和“后续检查结果”。本票先交付课程进度的领域边界；练习上下文在后续票继续使用同一进度/操作身份思路。

## 决策

1. **新增 `lesson_progress`。** 每课最多一行：`lesson_id`（唯一）、`generation_id`
   （唯一，生成幂等身份）、`generated`、`generated_at`、`opened`、`opened_at`、
   `browsed`、`browsed_at`、`view_submission_id`（唯一，最新浏览确认身份）、
   `view_submissions`（历史浏览身份）、`checked_count`、`passed_count`。
   旧课程没有该行时保持“状态未记录”；首次打开或浏览会建立 `generated=False` 的行，
   使用课程已知创建时间，不为旧内容补造“今天生成”或学习历史。
2. **状态规则是产品阈值。** `lesson_status(generated, browsed, checked, passed)`
   依次返回 `unavailable / unrecorded / browsed / weak / passed`。生成和浏览都不
   等于掌握；尚无短测时显示“待检查”，`passed` 只表示所测内容通过，不推广到全部单词。
3. **生成先校验后原子保存。** 校验唯一词形（大小写折叠）、必要释义、例句与翻译、
   对话中英文配对和提示类型；LLM 调用在写锁外，落库时复核目标级别、去重词形并写入
   词卡、课程和 `lesson_progress`。失败整体回滚，不留下半课或跳级；可选
   `operation_id` 重放返回同一课程，级别冲突返回 409，非法内容返回可解释失败且
   不消耗级别。
4. **打开与浏览确认分开。** `POST /api/lessons/{level}/opened` 只记录首次打开，
   不是学习完成。`POST /api/lessons/{level}/viewed` 接收 `{submission_id, revision}`：
   任一历史提交重放都不改写最新浏览时间，同一提交用于其他课程或课程内容已修订返回
   409，课程不存在返回 404；`browsed_at` 只取服务端确认时间。打开/浏览都不写学习
   事件、FSRS、正确率、连续学习日或每日完成。
   生成下一课同样使用稳定 `operation_id` 与独立待确认标记；响应丢失后重试不会跳级。
5. **V3 完整登记。** `lesson_progress` 作为扩展集合导出/校验/恢复：父引用
   `lessons`、ID 重映射、生成/浏览提交标识唯一、通过数不超过检查数。旧 V2 或早期
   V3 缺少该集合时保持“状态未记录”，恢复后不推算生成或浏览历史。
6. **列表与详情分开表达。** 列表分别显示已生成/已打开/已浏览/旧内容/状态未记录
   计数；二十课全部生成只显示“已生成”，不再显示学完。详情显示本课目标、学习状态与
   “短测：尚无（待检查）”，提供“内容已看完”和“稍后检查，继续下一课”两个显式动作；
   打开、浏览与后续检查各有独立状态。

## 补充：持久练习上下文（EL-08）

- 新增 `practice_sessions` / `practice_items`：轮次冻结用途、课程、规则版本、题序、
  内容修订与题目提示；题目只保存首答关联的真实 `ReviewEvent`，状态从事件读取，
  不复制成绩。
- 课程短测最多三道不同词（重复的课程词形只产生一道题）、少词按实数、零题返回不可用
  说明；优先选尚无独立回忆证据的本课词。题目只展示释义，不返回未作答题目的答案、
  长度或目标音频；帮助只提供首字母。
- 帮助通过独立接口持久合并（只增不减）；首答无提示全部正确为 `passed`，错误/辅助为
  `weak`，整轮跳过为 `incomplete`（未完成）且不改写课程检查计数；已完成轮次的即时
  重试不覆盖首答事件。
- 回看课程或刷新后再次进入同一课的短测会继续已有轮次，已请求的帮助不会清除；“新开
  一轮”或“只练薄弱项”才建立新轮次。
- 短测提交沿用统一学习提交的判分/事件/排期/幂等：事件携带练习轮次作为会话身份，同提交标识跨轮或跨入口复用按统一指纹返回 409；事务提交后才启动毕业句卡的 AI 升级。
- 轮到完成（`passed`/`weak`）时以首答事件更新课程的 `checked_count/passed_count`；评分仍由真实学习提交
  完成，短测不追加自评。
- 提交由统一学习提交按 `submission_id` + 业务指纹回放或返回 409，再核对冻结的内容
  修订；过期 409、删卡 404、非法组合 422。V3 中题目必须关联同一练习轮次、同一卡片、
  source=lesson 且 kind=typed 的真实首答事件；题目帮助只允许首字母。
- 删卡后按剩余题目的首答事件刷新课程检查计数；最后一道题也被删除时，轮次变为不可用
  且课程检查计数归零，不继续展示已被删除题目支撑的通过状态。
- 轮次、题目、首答事件关联与帮助状态随 V3 完整导出/校验/映射/恢复，恢复后可继续
  未完成轮次；旧 V3 缺少集合时预览明确列出。

## 回退方式

隐藏浏览确认入口后，保留已写入的 `lesson_progress` 与 V3 恢复适配，状态显示为已有
记录或未记录；不恢复“生成即完成”的文案，不清空已确认的浏览时间。功能回退与事务
回滚分别验收。

## 结果

- 生成、打开、明确看完与待检查分开；生成 20 课不会被展示为学完。
- 课程与词卡在同一事务内生成，非法内容与写入失败不留下半课或跳级。
- 课程状态、确认身份和关联随 V3 完整恢复；旧内容保持可读且不补造历史。

## 补充：指定词练习与本课保持（EL-10）

`targeted` 不携带课程或延迟窗口，首答仍关联 source=spelling 的真实事件；
`delayed_check` 的指定目标集合仍按真实间隔提交复核。两者共用原事务、幂等、提示与
恢复机制，冻结的题目顺序可重放，不新建平行的评分状态机。
本课保持从当前目标修订关联的延迟首测派生，不复制到 checked_count/passed_count。

## 补充：读后检查（EL-13 / #49）

- `story_check` 使用同一持久轮次、题目、统一学习事务与首答事件，不复制成绩。
  轮次引用不可变 `StoryVersion.version_id`；同一目标可有 `reading_choice` 和 `typed`
  各一道，最多两题。缺理解材料只出输入题，缺可输入目标只出理解题，缺全部材料显示空态。
- 理解题保存冻结的已校验题干、选项、答案和证据句；作答时由服务端签发并验证 choice
  上下文，事件为 `source=story / kind=choice / stage=standalone`，不排期。
  跳过不判分，但仍使用冻结选项保存反馈上下文。选择结果不变成自评或独立提取。
- 输入题只显示释义。回看原文前先在写事务中持久标记未完成题的 `answer_visible`；
  提示首字母同样只增不减。帮助确认失败不展示原文；已保存首答不因后续回看改变。
  无帮助输入沿用 FSRS 3/1，辅助输入不排期。结果分别展示阅读识别、词汇独立、辅助，
  即时正确不计延迟保持；再次作答必须显式新开一轮。
- 正常作答、保存失败、丢响应与刷新使用相同提交身份；已保存回放先于失效判断。
  新作答遇到故事/卡片修订返回 409，缺题或删除返回 404/不可用，非法选项返回 422。
  新用途创建请求不能混入课程、指定词或延迟窗口，轮次标识跨故事/版本复用返回冲突。
- 版本 UUID、题目上下文、首次事件与帮助随 V3 导出/校验/恢复；恢复重映射词卡 ID，
  验证题目和首答确实属于同一版本/修订。未作答选择在新实例重新签发，已保存回放使用
  原事件业务上下文；签名密钥不进入备份。旧轮次缺新增字段以 null 兼容。

放弃本地待确认作答只清除待确认身份，不删除服务端已接受的首答；界面随即从已保存轮次重选下一题或结果，不能停留在已处理题的输入表单。
