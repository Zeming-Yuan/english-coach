# ADR-0002：学习日与活动统计

- 日期：2026-10-30
- 状态：已采纳（EC-08）
- 关联：EC-03 学习事件、EC-09 指标分类

## 背景

旧统计直接读取 `reviews.last_review`，同一张卡每次复习都会覆盖原记录，导致跨天历史、
热力图和连续学习天数无法表达真实活动。学习日又依赖进程本地时间，上海午夜附近会错算。

## 决策

1. **时间存储与归属分离**：事件以 UTC 存储 `occurred_at`，写入时同时固定
   `learning_day` 与 `learning_timezone`。历史读取只使用存储的学习日；之后修改设置
   不会重写过去日期。
2. **完成词与练习次数分开**：
   - `reviewed_today`：当天 `scheduled=true` 的不同卡片数（同一卡多次只算 1）。
   - `attempted_today`：当天非跳过事件的条数（真实作答次数，重试回放不新增）。
   - `skipped_today`：当天 `skipped=true` 的事件数，单列。
3. **连续学习天数**：至少一次非跳过作答的学习日算活跃；今天未学但昨天活跃时从昨天
   起算，今天和昨天都无活动则为 0。
4. **历史零填充**：`/api/stats/history` 返回请求范围内每一天；`reviews` 为非跳过
   事件数，`reviewed_words` 为当天完成词（按卡去重），`new_cards` 只按该卡第一条
   真实排期事件计一次，迁移基线不计。
5. **旧历史诚实标注**：存在迁移基线时 `history_incomplete=true`；基线只展示最后可知
   活动与累计次数，不伪造日期、不进入正确率或连续天数。

## 自适应新词建议（EC-09）

- 样本取近 7 个学习日内、同卡同日的第一条可排期事件（自评或独立输入）；
  迁移基线、`legacy`、带辅助输入、选择题与跳过均不进入样本。
- 1–2 分视为需要强化，3–4 分视为通过；同日重做不会覆盖首答。
- 错误率 >30% 建议 5；样本至少 20 且错误率 <15% 建议 15；其余默认 10。
  样本不足 20 不自动上调，高错误率仍可下调。阈值是产品默认值，不是科学定论。
- 每日完成目标与新词配额分离：提高目标不会把下调后的新词量抬回去。

## 后果

- 旧统计测试中直接构造多行 `Review` 的样本已改为真实评分事件。
- 统计读取不再依赖 `reviews` 当前状态；旧字段保留为兼容输出。
- 自适应新词建议读取排期事件，不再使用会被覆盖的 `reviews` 当前状态。

## 每日主队列（EC-13）

- `/api/today.queue` 为去重的每日主队列，原数组保留兼容。只从当前记忆状态选择到期
  单词，先放最多 20 张复习，再加入建议配额内的新词；错误权重、困难标记仅在各组内
  排序，不把未到期卡变成到期卡。重复旧状态按 ADR-0001 选择当前行。
- `remaining_due` 是本轮之外的到期张数，完成后可继续下一轮；`target` 是开始时本轮
  实际卡数，保存成功只增加进度，不缩小目标。
- 每日最低完成目标、新词建议与本轮目标分别展示；提高最低目标不增加新词配额。

- 每日主队列只有一个进度来源：持久化的轮次索引。当前卡保存确认后按会话和卡片匹配推进，
  迟到的旧卡确认不能重复推进或回退。首页提供刷新恢复；进入闪卡后由学习页独占
  待确认控件，首页已发出的确认若迟到也按同一进度来源核对。专项自评保留独立进度。
- 只有已确认命令的 `session_id` 属于当前轮次且 `stage=main` 时才推进每日主队列。
  同一卡的其他专项待确认记录可以保存，但不计入本轮，也不丢弃当前问题；首页已发出
  的异步确认在切换到学习页后完成时，同样核对来源并解除已解决的待确认状态。

## 有限巩固与本轮反馈（EC-14）

- 主队列完成后，从本轮已保存的答错、1–2 分和显式跳过项按卡去重，提供最多三道既有输入题；词库很小也可独立拼写，无有效题时正常结束。巩固保存相同 `session_id`、`source=reinforcement` 和 `stage=reinforcement`，复用输入题的提示与排期规则，不调用 AI 出题。
- 已保存巩固卡不再次发题，前三个候选槽位不会因完成而补入第四题；刷新继续读取已提交事件。用户可以跳过整个阶段，此动作不生成未作答题的虚假答错或掌握事件。
- 完成页只读取服务端已保存事件，分别展示主队列/巩固次数、成功排期的不同卡片数、独立提取、辅助、识别、自评分与跳过数；读取不新增学习事件。课程生成不属于本轮完成证据。
- 仍需复习项只有在后续独立输入答对或显式自评分 3–4 分后才清除；辅助或识别答对不足以清除。下一步只显示当前真实已有排期；完成本轮不代表长期掌握，也不承诺不会遗忘。
- 主队列显式跳过使用 `self_rating`、`skipped=true`、`rating=null`，正误为空、不排期、不改变错词权重；非跳过自评仍必须提供评分。既有事件字段与 V2 备份结构不变。
- 浏览器保留本轮初始巩固卡 ID，仅固定题目槽位，避免删卡级联删事件后补入第四题；剩余题与反馈仍从服务端已保存事件读取，不维护第二个作答进度。HTTP 接口不承诺服务端持久会话：删除关联事件后可改变候选，全部事件删除后会话为未知；数据库备份不保存浏览器轮次。
- 同一时间戳的事件仍按数据库实际保存次序解释。新 V2 导出按 `occurred_at`、SQLite `rowid` 排列学习事件，恢复保留事件数组次序，修订摘要保留该次序（其他集合按 ID 规范化）。已导出的旧文件若按随机 UUID 排列并丢失同时间先后，则无法反推旧顺序，不补造。

## 补充：延迟回测（EL-09，2026-11-02）

- 隔日窗口严格为 UTC 实际时长 `[86400, 259200)` 秒，一周为
  `[604800, 1209600)` 秒，其余单列“其他间隔”；学习日仍取事件保存时固定的归属。
- 发题只选当前修订中同时具有非跳过学习事件与确认接触的词，最多三题，优先到期、
  薄弱项，再按最后记录时间与稳定身份排序。无候选不阻止普通练习，不延后正常 FSRS。
- 题目冻结锚点（真实事件 UUID 或接触 submission_id）、时间、发题窗口；提交在
  `BEGIN IMMEDIATE` 事务内复核最新记录并重新分类。当前作答之后的答案回显不取消
  已成立资格；未确认接触只降低完整性，不能提供更早的时间。
- 每词/修订/学习日/实际窗口只取首次处理结果；同时间戳按学习事件保存次序。
  独立正确/错误进入分母，辅助、跳过与不完整依据分别展示，重做不替换首测。
- 统计显示成功/独立样本、辅助、跳过、覆盖词数与实际间隔；零样本“暂无数据”，
  不足十个提示“样本较少”，不推断全部词汇能力。
- 回测输入复用统一学习写入，仅原输入排期一次，不追加自评。完整事务失败不留下
  结果或排期；同提交回放先于修订检查，同身份异内容返回 409。

## 补充：统计到行动（EL-10，2026-11-02）

- 建议从当前修订的真实事件重算，固定顺序为最近独立首答失败、只有辅助成功、合格延迟
  候选；按规范化词形跨理由去重，最多三项、每项三个词。建议不持久化为第二份成绩。
- 独立样本沿用同词同学习日首个 typed 再判独立的规则；辅助次数不扩大独立样本量。
  不足十个独立样本必须说明依据有限；无样本不判断能力差，识别错误不生成提取失败建议。
- GET 建议严格只读，不调用评分或 FSRS。未到期的专项也由用户明确启动。
- 本课延迟统计按本课当前目标身份/修订关联真实延迟首测，独立、辅助、跳过分别统计；
  课程短测计数继续独立，生成/浏览或全站回测成绩均不表示本课短测通过。
