# ADR-0002：学习日与活动统计

- 日期：2026-10-30
- 状态：已采纳（EC-08）
- 关联：EC-03 学习事件、EC-09 指标分类

## 背景

旧统计直接读取 `reviews.last_review`，同一张卡每次复习都会覆盖原记录，导致跨天历史、
热力图和连续学习天数无法表达真实活动。学习日又依赖进程本地时间，上海午夜附近会错算。

## 决策

1. **时间存储与归属分离**：事件以 UTC 存储 `occurred_at`，写入时同时固定
   `learning_day` 与 `learning_timezone`。历史读取只使用存储的学习日；之后修改设置
   不会重写过去日期。
2. **完成词与练习次数分开**：
   - `reviewed_today`：当天 `scheduled=true` 的不同卡片数（同一卡多次只算 1）。
   - `attempted_today`：当天非跳过事件的条数（真实作答次数，重试回放不新增）。
   - `skipped_today`：当天 `skipped=true` 的事件数，单列。
3. **连续学习天数**：至少一次非跳过作答的学习日算活跃；今天未学但昨天活跃时从昨天
   起算，今天和昨天都无活动则为 0。
4. **历史零填充**：`/api/stats/history` 返回请求范围内每一天；`reviews` 为非跳过
   事件数，`reviewed_words` 为当天完成词（按卡去重），`new_cards` 只按该卡第一条
   真实排期事件计一次，迁移基线不计。
5. **旧历史诚实标注**：存在迁移基线时 `history_incomplete=true`；基线只展示最后可知
   活动与累计次数，不伪造日期、不进入正确率或连续天数。

## 自适应新词建议（EC-09）

- 样本取近 7 个学习日内、同卡同日的第一条可排期事件（自评或独立输入）；
  迁移基线、`legacy`、带辅助输入、选择题与跳过均不进入样本。
- 1–2 分视为需要强化，3–4 分视为通过；同日重做不会覆盖首答。
- 错误率 >30% 建议 5；样本至少 20 且错误率 <15% 建议 15；其余默认 10。
  样本不足 20 不自动上调，高错误率仍可下调。阈值是产品默认值，不是科学定论。
- 每日完成目标与新词配额分离：提高目标不会把下调后的新词量抬回去。

## 后果

- 旧统计测试中直接构造多行 `Review` 的样本已改为真实评分事件。
- 统计读取不再依赖 `reviews` 当前状态；旧字段保留为兼容输出。
- 自适应新词建议读取排期事件，不再使用会被覆盖的 `reviews` 当前状态。

## 每日主队列（EC-13）

- `/api/today.queue` 为去重的每日主队列，原数组保留兼容。只从当前记忆状态选择到期
  单词，先放最多 20 张复习，再加入建议配额内的新词；错误权重、困难标记仅在各组内
  排序，不把未到期卡变成到期卡。重复旧状态按 ADR-0001 选择当前行。
- `remaining_due` 是本轮之外的到期张数，完成后可继续下一轮；`target` 是开始时本轮
  实际卡数，保存成功只增加进度，不缩小目标。
- 每日最低完成目标、新词建议与本轮目标分别展示；提高最低目标不增加新词配额。

- 每日主队列只有一个进度来源：持久化的轮次索引。当前卡保存确认后按会话和卡片匹配推进，
  迟到的旧卡确认不能重复推进或回退。首页提供刷新恢复；进入闪卡后由学习页独占
  待确认控件，首页已发出的确认若迟到也按同一进度来源核对。专项自评保留独立进度。
