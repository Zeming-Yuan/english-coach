# ADR-0005：学习证据与内容修订关联

- 状态：已采纳
- 日期：2026-10-31
- 票据：EL-02（独立作答后，在词卡详情看到有依据的回忆状态）

## 背景

现有详情用复习次数或毕业状态推算“掌握百分比”：答错也可能增加累计次数，自评高分
与独立拼写被混在一起展示。用户无法判断当前内容是否真的被独立回忆出来，也无法
区分旧修订的历史结果。ADR-0004 已为每张卡建立内容修订身份；本票把学习事件绑定
到提交时的修订，并只从当前修订的真实事件生成证据摘要。

## 决策

1. **事件携带修订关联。** `ReviewEvent` 增加可空 `card_identity` 与
   `card_revision`。新提交在统一写事务中读取当前修订并同时写入事件；升级前的旧
   事件保持空值，不补造关联，也不改写缓存响应或迁移基线。V3 备份的
   `learning_events` 行包含这两个字段；V2/V1 文件没有它们，恢复后旧事件为空值。
2. **证据只取当前修订。** `evidence_summary(db, card_id, runtime)` 先按
   `card_identity + card_revision` 限定当前修订，再筛选 `kind=typed`、
   `source != legacy`、未跳过、已判分且 `assistance=[]` 的事件。辅助、识别、
   自评、跳过与迁移基线不进入独立回忆样本。旧修订事件保留为历史，不证明新内容。
3. **回忆规则是产品阈值。** 同一学习日先取首个 typed 作答（按保存次序），只有它
   未使用辅助、未跳过且已判分时才成为独立样本；先辅助后同日重试不能算独立首答。
   最近一次独立首答错误时状态为 `weak`；至少两个不同学习日、首答独立正确且时间
   相隔 ≥24 小时才为 `verified`；距今超过 30 天为 `stale`。可见状态只有
   `insufficient / verified / weak / stale / history_incomplete`，不输出百分比或
   概率。规则版本 `rule_version` 随摘要返回但不持久化；事件与修订关联是可重算
   依据。
4. **历史完整性单独表达。** 存在迁移基线、`source=legacy` 事件或未绑定修订的旧
   事件时，回忆状态为 `history_incomplete`；历史成功仍保留日期可查看，但不冒充
   当前掌握。`graduated` 继续只表示句子练习解锁，不是回忆证据。
5. **尚无线索的维度显式无证据。** `retention`（延迟保持）与 `application`
   （实际应用）在后续票引入前固定为 `insufficient / count=0 /
   last_verified_at=null`，不偷读毕业或复习次数。
6. **公开边界。** `GET /api/cards/{id}` 增加 `learning_evidence`：
   `{revision, rule_version, progress_label, recall, retention, application}`，
   每个维度 `{status, label, count, last_verified_at}`。详情同时保留真实 FSRS 到期、
   复习次数与句子练习解锁标签（不再显示“已毕业/100% 掌握”）；删除词卡级联删除
   事件，证据随卡消失。
7. **V3 兼容。** 事件修订字段随 V3 `learning_events` 导出/校验/恢复；两个字段要么
   同时为空、要么同时有效（identity 为 UUID，version ≥1）。旧 V2/V1 恢复产生的
   事件为空值，读取时显示 `history_incomplete`，不伪造当前证据。
8. **所有进展入口共用同一标签。** `evidence_label` 固定为
   `独立回忆已有证据 / 仍需巩固 / 历史证据，待复测 / 历史依据不完整 /
   独立证据不足`，未知状态降级为“独立证据不足”。词表批量返回
   `learning_evidence` 与 `progress_label`；首页队列只返回 `progress_label` 与
   聚合计数；统计返回
   `evidence_counts / evidence_labels / evidence_samples / evidence_latest_at`，
   不替代原有题型正确率。
   词表的“毕业”徽标改为“已解锁”，详情显示“句子练习已解锁”；分享图在导出时
   读取同一统计，绘制解锁数与独立证据样本/日期，不画 100% 掌握。句子卡不进入
   词卡的证据计数，避免永远“证据不足”的句子卡稀释统计。

## 回退方式

详情退回原始事件列表并显示“依据不足”的保守状态，保留证据 API、规则版本与原事件；
不恢复按复习次数计算的 100% 掌握。已写入的事件修订关联与 V3 数据继续可读，不删除
字段或用旧快照覆盖。

## 结果

- 独立作答、辅助、识别、自评与跳过分开解释；反复失败不会显示为掌握。
- 修改词义后旧证据成为历史；恢复与重放不会重复产生或刷新证据。
- 延迟保持与实际应用在对应功能交付前明确显示“暂无证据”，而不是借用其他指标。

## 补充：应用内接触（EL-04）

- 新增 `learning_contacts` 集合：`submission_id`（唯一）、`card_id`、
  `card_identity`、`card_revision`、`source`、`kind`、`occurred_at`。客户端只在
  词卡详情或词表真正显示（`answer_visible`）、或答案语音真正开始播放
  （`answer_audio`）后确认；预取、语音预热、未进入视口的卡片与失败播放不发送请求。
- `occurred_at` 只取服务端确认时间，请求不接受客户端回填日期；延迟确认不会制造
  更长的间隔证据。接触不是作答：不写学习事件、FSRS 排期、正确率、连续学习日或
  每日完成。
- `GET /api/cards/{id}` 增加 `last_contact` 与 `contact_integrity`。没有记录
  （包括旧数据与旧备份恢复）时为 `unknown / missing_history`，不宣称“从未接触”；
  有记录时为 `confirmed / server_confirmed`，并显示当时修订。
- 同提交标识的同内容回放返回原记录；同标识不同内容、展示后内容已修订或目标已删除
  分别返回 409/409/404，不写入新接触。删除词卡级联删除接触。
- 前端待确认标记使用 `ec.contact.*` 独立前缀，不会被评分恢复界面当作学习提交；
  保存失败或本地存储不可用时详情显示“接触依据不完整”，网络恢复后沿用同一提交
  标识重试。
- `learning_contacts` 作为 V3 扩展登记：父引用 `cards`、ID 重映射、UUID 校验、
  提交标识唯一；接触的修订身份必须与快照中的内容修订一致，版本不得晚于当前修订。
  旧 V2 或早期 V3 没有该集合时，预览明确列为缺失，恢复后保持未知。

## 补充回退方式

停止上报接触时，把间隔展示降为“依据不足”，保留已确认记录、V3 导出与恢复适配；
不把停止记录当作“没有接触”，也不删除已写入的接触行。

## 补充：现有练习入口覆盖（EL-05）

- 接触来源扩展为 `study / spelling / quiz / listening / mixed / reinforcement`；
  所有来源共用 EL-04 的服务端确认、服务端时间、幂等与 V3 恢复规则。
- 答案展示/播放的接入点：
  - 闪卡翻到背面（显示释义/翻译）→ `answer_visible`。
  - 拼写答错或跳过时显示正确拼写 → `answer_visible`；答对只显示用户输入，不算展示答案。
  - 测验的选择/相关词选项里出现目标英文 → `answer_visible`；输入题答错显示答案 → `answer_visible`。
  - 听写每次实际播放目标词 → `answer_audio`；选项出现目标英文 → `answer_visible`。
  - 混合练习按题型复用上述规则；有限巩固只在实际显示正确拼写时记录。
  - 所有入口的答案语音只在播放真正开始后记录 `answer_audio`；预取、失败播放不记录。
- 提示只增不减：`merge_assistance(previous, added)` 保留已请求的提示并拒绝未知项。
  前端按稳定题身份保存 `ec.assistance.<scope>:<card>:<type>`，关闭提示、切换页面或
  恢复同一待确认题仍按辅助记录；成功保存后清除，新抽取题从独立开始。
- 接触与作答各自幂等：接触使用自己的 submission_id，不会复用或占用学习事件的
  提交标识；作答保存失败保留当前题、待确认请求与帮助状态。

- 提示状态保存在浏览器 `ec.assistance.<scope>:<card>:<type>`，属于待确认 UI 状态，
  不进入 V3；真正写入学习事件后，事件中的 `assistance` 随 V3 导出/恢复。

- 题身份使用“来源 + 卡 + 题型”。同一题未提交时切换页面会恢复提示；成功保存后清除，
  新抽取题从独立开始。未提交即放弃的提示会保守保留到同卡同型的下一次抽取——只会
  更保守，不会把辅助作答算成独立。提示键使用本地卡 ID；V3 恢复重映射卡 ID 后，
  旧提示不会迁移到新 ID，恢复后的题从独立开始（需要重新请求提示），不会把
  未提示的题错误算作辅助。

## 补充：课程、故事与内容改写（EL-06）

- 课程详情返回课程修订、词卡修订与每句对话的 `visible_card_ids`；故事详情返回故事
  修订、词卡修订、正文实际出现的 `visible_card_ids` 与逐行 `line_card_ids`。
  只有正文/词表实际呈现的目标词才上报接触；子串、大小写、重复都不改变目标身份。
- 阅读页批量上报 `source=lesson/story` 的 `answer_visible`；句子朗读在实际播放开始
  （`onStarted`）后上报 `answer_audio`；点词弹层显示释义时上报该目标词。接触确认
  失败不阻断阅读，只提示依据不完整；阅读与列表是纯读，不写学习事件、排期或日完成。
- 故事补翻在调用 AI 前记录故事 identity+version；返回后若已编辑、恢复或换实例导致
  不一致，丢弃晚到翻译，不覆盖新内容；接受翻译时推进故事修订。

## 补充：长间隔保持与恢复（EL-09，2026-11-02）

- `delayed_check` 复用持久练习上下文；入口与题目前仅显示中文释义，首页推荐词 chip
  改为释义，避免在回测前泄露目标英文。提示与错误/跳过后的答案回显仍记录真实接触。
- 当前修订有效一周首测独立成功才产生“长间隔保持已有证据”；新的独立错误使其待巩固，
  超过 30 天显示待复测，历史成功日期保留。隔日、辅助、跳过、未完整确认的间隔不冒充
  一周保持；语境应用维度仍无证据。
- 浏览器每次创建/提交携带待确认接触标记（存储不可用也保守降级）；客户端不能传入
  权威间隔。服务端按已保存记录取时间，多个标签页通过同一写事务观察最新接触。
- V3 的 `practice_sessions` 增加窗口与待确认标记，`practice_items` 增加冻结依据及首测
  分类；真实事件/接触 UUID 保持稳定，卡 ID 按已有映射恢复。校验锚点目标、修订、真实
  时间、实际窗口及首答事件引用，拒绝绕过较新记录的旧锚点；恢复不执行评分或刷新证据。
- 旧 V1/V2/V3 缺少回测数据不补造样本，预览说明“没有延迟回测记录”；旧数据可普通练习
  建立当前修订的新依据。无候选轮次允许重新查找候选。
- 功能回退隐藏首页/统计的回测入口，保留轮次、结果、事件、真实排期和 V3 适配；不执行
  破坏性 downgrade、不恢复旧快照。只读统计/导出仍可验证已有结果，普通练习继续可用。

- 回退配置为 `DELAYED_RECALL_ENABLED=false`，重启后隐藏首页和统计的回测按钮；
  统计、轮次读取、原请求确认、V3 导出/恢复与普通练习继续可用。此开关是功能回退，
  不是权限控制或数据删除。HTTP 与双视口浏览器场景覆盖该路径。
- `GET /api/practice-sessions?purpose=delayed_check&window=day|week` 只返回最近未完成
  轮次身份；新浏览器或 V3 恢复后可以从可见入口继续，不要求注入本地存储。

- 审查补充：重新打开/恢复轮次时，已保存答案、首字母和错误反馈只在进入视口后确认
  新接触；已失效修订只显示历史结果，不自动展开旧英文。课程短测复用同一呈现规则。
- 新保存的 legacy 非跳过输入仍保守重置相关接触时间；legacy 不参与独立失败或保持样本。
  在线判定与 V3 校验采用同样的锚点资格，避免应用自己的导出不能恢复。
- 失败提交的表单重试、刷新后的全局确认都在每次发送前合并当前待确认接触，只增不减，
  保留原 submission_id/答案。服务端已接受的重放仍返回原结果，不反向取消已成立资格。

## 补充：建议的目标与接触（EL-10，2026-11-02）

- 建议响应提供具体依据事件 ID、独立样本量、中文释义、目标 card_id 与当前修订。
  延迟建议仅显示数量、中文和相关课次，不提前返回英文答案。用户主动展开后只在实际
  可见时确认答案接触，失败保留原接触提交并提示，成功后重算延迟资格。
- 专项复用持久练习上下文，新增 `purpose=targeted`；回测仍使用 `delayed_check+window`，
  可指定同一目标集合。创建事务逐项校验身份、修订和回测资格；删除 404、变化 409、非法
  组合 422，不以新候选替换原目标。空池说明原因并提供返回建议入口。
- V3 接受并校验 targeted 用途，复用已登记轮次/题目/事件集合和 card_id 映射；不新增表。
  旧格式或无专项轮次时预览 `targeted_history=not_recorded`，不从旧成绩补造专项记录。
- `LEARNING_ADVICE_ENABLED=false` 只隐藏建议入口；已产生学习、轮次、接触与 V3 兼容
  保留，继续可读、可导出；不恢复旧快照、不清空事件、不撤回真实排期。

审查补充：多词专项/回测轮次任一目标删除后，将已有轮次生命周期设为 unavailable，
保留剩余冻结题用于历史解释；不得缩小原集合后判通过，后续新提交拒绝。
V3 允许此类非课程轮次保留剩余题目和不可用状态，恢复后仍不可推进。
浏览器恢复成功清除旧建议请求入口；建议区也校验旧轮次并查找导入的活动轮次，
提供明确放弃入口，避免旧请求遮住恢复结果。

延迟建议的独立样本量与回测支持事件引用分开：只有自评或辅助错误时，独立样本量仍为 0，
但保留当前修订最近一次非跳过事件作为回测依据的可追溯引用，不把该引用计为独立正确样本。


## EL-20：内部消费者最终边界

实际展示/播放继续经显式接触确认；接触不复制为学习成绩。V3 同时间接触按原 ID 保存顺序恢复，最近来源与确认时间保持可解释；重复确认仍返回原时间，未保存的退役 ID 请求不能写入恢复后实体。

最终 owner/现存调用者、回退与实际验证范围见 [EL-20 契约核对](../verification/el20-contract-evidence-consumers.md)。
