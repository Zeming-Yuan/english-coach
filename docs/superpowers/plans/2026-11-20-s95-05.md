# S95-05 普通五题测验出相关词题 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 五题测验在存在合适素材时实际出现一道答案唯一的相关词题。

**Architecture:** 复用现有 related 签名题目与服务端识别判分，在既有题量内安排一道题，缺素材时沿用有效原题型。保留识别、输入与自评的证据边界。

**Tech Stack:** React 19、FastAPI、SQLAlchemy/SQLite、pytest、Playwright。

**Spec:** https://github.com/Zeming-Yuan/english-coach/issues/95 。实施前同时读取父规格 A/B 验收条目。

## Review Focus

1. 只有五张词卡也能进入 related 分支，Task 1 首条 HTTP 红测验证。
2. 空释义、同形原词、重复或含糊答案不能构成有效题，Task 1 参数化数据验证。
3. 小词库或无 related 材料仍能返回有效题，Task 1 原有回归验证。
4. 题目发出后内容修订改变，保存返回 409 且不写错卡，Task 2 签名/修订测试验证。
5. 保存响应丢失后同 submission 回放不重复事件，识别正确不提高独立回忆，Task 2 验证。

### Task 1 在固定题量内安排有效题

- [ ] 向 `tests/test_quiz.py` 写首条失败测试，复用已存在 `make_quiz_cards`。

```python
def test_five_question_quiz_can_include_related(client, db_session):
    make_quiz_cards(db_session)
    apple = db_session.query(Card).filter(Card.word == "apple").one()
    apple.related_words = [
        {"word": "applesauce", "meaning": "苹果酱", "kind": "compound"},
        {"word": "apply", "meaning": "申请", "kind": "lookalike"},
    ]
    db_session.commit()
    questions = client.get("/api/quiz?limit=5").json()["questions"]
    assert len(questions) == 5
    related = [q for q in questions if q["type"] == "related"]
    assert len(related) == 1
    assert len(set(related[0]["options"])) >= 2
    assert related[0]["question_token"]
```

- [ ] 运行 `.venv/bin/python -m pytest tests/test_quiz.py -k five_question_quiz_can_include_related -q`。当前 related 只在 `len(selected) >= 6` 内出现，预期 related 数量为 0。
- [ ] 从全部单词卡提取有效 related 候选，选择一张加入 selected，或替换末位为有素材卡，题量仍受 limit 限制。在非输入题槽位优先安排一条 related，其余保留既有题型。可作为候选筛选的最小条件如下。

```python
related = [
    item for item in (card.related_words or [])
    if isinstance(item, dict)
    and isinstance(item.get("word"), str)
    and item["word"].strip()
    and isinstance(item.get("meaning"), str)
    and item["meaning"].strip()
    and item["word"].strip().casefold() != card.word.strip().casefold()
]
```
