# 无 AI 时完成一节示范课 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal** 课程首页可离线阅读已核对的示范课并完成一道示例任务，同时清楚说明正式生成需要的 AI 配置。

**Architecture** 本地示范材料用纯读接口返回，以 `mode=demo` 区分正式课程。示范页复用课程的词表、对话与听读表现，示例答案只驻留该页面内存，不调用正式课程生成、浏览确认或短测写接口。正式生成继续使用稳定 operation_id。

**Tech Stack** FastAPI、React、SQLite、pytest、Playwright。

**Spec** https://github.com/Zeming-Yuan/english-coach/issues/95 ，B1、B6。候选 08 无业务前置。

## Global Constraints

- 「免配置材料先用本地。」
- 「示范课不自动完成正式课程。」
- 「课程的生成、打开、浏览及短测结果保持分开」
- ADR-0004 新持久集合须当票纳入 V3。本设计使用纯读材料与页面内存，无新集合。
- 执行前读最新 dev、运行 `.venv/bin/python scripts/agent_check.py --base dev`。计划依据已核对的 `5110e22`，执行者需复核届时文件内容。

## Review Focus

1. 未配置与配置读取失败分别显示可配置/可重试，不能制造生成待确认记录。任务 2 测试。
2. 演示返回后正式课程仍为零，示例答对不变成正式短测通过。任务 1 与 2 测试。
3. 重复开关演示保留正式生成待确认请求，不能误清除。任务 2 测试。

5. 已有正式课程与已配置 AI 的正常生成继续可用。任务 2 回归。

import {test, expect} from './support/test.mjs';
test('S95-08 demo lesson completes without formal progress', async ({appFactory, page}) => {
  const app = await appFactory({fixture: 'ec01-missing.json'});
  const before = await (await app.request.get('/api/export/backup')).json();
  await page.goto(app.baseURL);
  await page.getByRole('button', {name: '打开课程', exact: true}).click();

  await page.getByRole('button', {name: 'Hello!', exact: true}).click();
  await expect(page.getByRole('status')).toContainText('示例任务已完成');
  await page.getByRole('button', {name: '返回课程', exact: true}).click();
  const after = await (await app.request.get('/api/export/backup')).json();
  expect(after.lessons).toEqual(before.lessons);
  expect(after.learning_events).toEqual(before.learning_events);
  expect(after.extensions).toEqual(before.extensions);
  await page.getByRole('button', {name: '配置 AI 服务', exact: true}).click();
  await expect(page.getByRole('heading', {name: /AI 服务/})).toBeVisible();
});
