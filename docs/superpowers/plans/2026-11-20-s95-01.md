## Global Constraints

- 最高入口为真实桌面和手机浏览器，生产前端、迁移后的隔离库。复用 `e2e/support/test.mjs` 的 `app` / `appFactory`，禁止用全量 mock API 代替主路径。
- 「太简单」保存原自评后继续。「多学一个」只打开。「加入学习」才保存。同次超时重试沿用身份，主动新练习另建身份。
- 每日开始后卡序和总数冻结。接触、自评、识别、辅助输入、独立输入按 ADR-0005 分开。
- 内容修订、恢复与 V3 适配按 ADR-0004 同票交付。只追加兼容结构，不破坏性 downgrade，不用旧快照覆盖新学习。
- 执行前 fetch origin，从最新 origin/dev 建立独立 checkout，运行 `.venv/bin/python scripts/agent_check.py --base dev`。同一服务文件、迁移头和备份登记表串行整合，base 变化后重跑相关回归。
- 每个提交先添加并运行失败测试，再最小实现，再通过测试再提交。保留实际 base/head、命令、结果和未验证项。产品切片执行独立 Standards/Spec 审查。

**Goal:** 在当前闪卡翻面后发现并查看扩展词，关闭回到原卡，并在详情复用同一操作。持久 daily 会话和直接 starter 闪卡队列分别验收。

**Architecture:** 在现有 `WordExpansions` 上增加选择与预览，放在翻面卡容器外，避免词条按钮冒泡触发翻面。复用现有补全 API 和 starter 内容，预览使用现成材料，不新增持久表。

**Blocked by:** None。先交付本票，再串行整合 S95-02。

## Review Focus

1. 旧未分类 related_words 仍展示为「相关词」，失败补全不丢旧内容。
2. 空材料和句子卡仍可继续正常学习。
3. 补全过程换卡后迟到响应不能写入下一张。
4. 查看及朗读失败不评分、不加词、不推进队列。
5. 手机、键盘关闭后焦点回原触发按钮，卡片仍翻面。

import {test, expect} from './support/test.mjs';
test('S95-01 exploration returns to flipped apple', async ({app,page}) => {
  await page.goto(app.baseURL);
  await page.getByRole('button',{name:'体验入门词卡',exact:true}).click();

  const trigger=page.getByRole('button',{name:'多学一个',exact:true});

  const region=page.getByRole('region',{name:'构词与扩展'});

  await expect(region).toContainText('applesauce');
  await expect(region).toContainText('形近词');
  await region.getByRole('button',{name:/apply/}).click();

  await page.getByRole('button',{name:'返回原词卡',exact:true}).click();

  const rows=(await (await app.request.get('/api/cards')).json()).cards;

  expect(rows.every(c=>c.review_count===0)).toBe(true);

const [expansionOpen,setExpansionOpen]=useState(false);
