**Goal:** 显式把所选单词或短语加入词库，确认同次保存，返回冻结的原学习轮次。

**Architecture:** 增加独立的扩展加入命令，复用单一写事务、内容修订及 V3 登记。目标身份只按规范词形和 kind 查找，命令记录缓存首次响应，前端 pending 在发送前保存，复用现有卡 ID 退休和恢复重映射机制防止旧页面写入。

**Blocked by:** S95-01。与 S95-04 的手动加词对同一 card identity/write 路径串行整合。

## Review Focus

1. 回包丢失/刷新/连点，同一请求得到同一 card_id。
2. 同一操作号改变目标返回 409，已有用户词义和历史保留。
3. 单词、内部含空格短语、同形 sentence 分清身份。
4. 删卡、修改来源 revision 或全量恢复后，旧请求不可复活或改写对象。
5. 同时写入与提交失败整体回滚，V3 往返保留关联和幂等身份。

## 文件与接口

- 修改 `app/routers/cards.py`，新增只读 `GET /api/expansion-additions?target_card_id=<id>`（已提交关系列表）、`GET /api/expansion-additions/{operation_id}` 与 `POST /api/cards/{source_id}/expansion-additions`。新建 `app/schemas/expansion_additions.py`、`app/services/expansion_additions.py`、`app/models/expansion_addition.py`。
- 请求 `{operation_id,source_revision,target:{word,meaning}}`，目标必须出自当前来源 related_words 的非 formation 条目，服务端取义项，不能信任任意客户端内容。pending 外层另存 `source_id` 与 `study_session_id`，保证刷新后能重建原路径和原轮导航。
- 确认响应 `{committed:true,operation_id,card_id,created,available}`。重复同语义操作回放原响应，同操作号异内容 409，未提交时来源删除 404，来源修订过期 409。已提交记录优先只读回放，返回原 operation_id 与当前可读取的目标卡引用，不重新写卡。未提交记录才验证当前路径的原生来源 ID 与修订，已退休来源 404、修订不同 409。
- 新模型持久字段 operation_id 唯一、来源 card nullable FK/身份/版本、目标 card nullable FK、原请求 source_id 快照、规范化 target、fingerprint、response。GET 返回 `{operation_id,source_card_id,target_card_id,available}` 并从当前 FK 读取，供完成页/详情找关联。删除来源或目标时 FK 置空并保留已提交操作，原请求 source_id 快照用于核对只读回放，不能用于重新写入。所有写入在 `run_write` 内，新增 Card 同事务初始化 revision。
- 添加 Alembic 加法迁移，从执行时最新 head 继承。修改 `app/services/backup_v3_registry.py`、`app/schemas/backup_v3.py`、恢复流程，将操作集合引用映射、缓存响应中 card_id 的重映射纳入同票，原请求 source_id 快照保持原值。复用 `app/services/restore.py` 的卡 ID 退休机制。恢复后可以读取已恢复的操作及当前目标，未提交的旧 pending 按已退休来源拒绝，不能把旧 URL 自动改为恢复后的来源继续写。
- 新建 `frontend/src/lib/expansionAdditions.js` 和单测，修改 `ExpansionPreview`、首页 pending recovery 展示，pending 使用 account scope。新增 `tests/test_expansion_additions.py`、`e2e/s95-02.spec.mjs`。

```python
from uuid import uuid4

def test_addition_replays_one_card(ec):
    source=ec.seed_card('apple',meaning='苹果',related_words=[
        {'kind':'lookalike','word':'apply','meaning':'申请'}])
    rev=ec.client.get(f'/api/cards/{source}').json()['content_revision']
    payload={'operation_id':str(uuid4()),'source_revision':rev,
             'target':{'word':'apply','meaning':'申请'}}
    url=f'/api/cards/{source}/expansion-additions'
    first=ec.client.post(url,json=payload)
    again=ec.client.post(url,json=payload)
    assert first.status_code==again.status_code==200
    assert first.json()==again.json()
    assert first.json()['committed'] is True
    rows=ec.client.get('/api/cards').json()['cards']
    assert len([r for r in rows if r['word']=='apply' and r['kind']=='word'])==1
```
