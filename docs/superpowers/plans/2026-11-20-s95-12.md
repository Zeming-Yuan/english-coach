# 学习记录分开统计词句并直达巩固 · Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal**　学习者在首页、学习记录和成绩单读到相同的词卡数与句子卡数，在记录首屏能针对真实的 dog 首答错误开始巩固。

**Architecture**　从当前词卡按 kind 聚合，扩展现有只读统计响应。首页、记录和成绩单读取同一口径，继续使用现有建议与专项练习服务。判分、队列、恢复均沿用原契约。

**Tech Stack**　FastAPI、SQLAlchemy、SQLite、React、Canvas、pytest、Playwright。

**Spec**　[规格 #95 的 B5](https://github.com/Zeming-Yuan/english-coach/issues/95)。复用 [专项建议 #46](https://github.com/Zeming-Yuan/english-coach/issues/46)。

## Global Constraints

- 验收入口为真实迁移库、生产前端、桌面和手机的「首页 → 学习记录 → 建议练习」与「学习记录 → 成绩单」。
- 保留 `total_cards` 的全卡总数语义及 `graduated` 的已达到解锁条件的单词数语义。已有调用者仍可按原字段工作。历史备份通过恢复后的现有词卡重新聚合。
- 读建议与导出成绩单都是只读操作。只有用户点开始并提交作答，才可能新增练习记录。独立首答、辅助、识别、自评沿用 ADR-0002、0005。
- 与 S95-07 的首页修改串行合入。先合入者不依赖另一票，后合入者对最新 dev 跑两票的首页回归。无 schema 迁移。

## Review Focus

| 状态反例 | 必须固定的测试 |
| --- | --- |
| 同一词形已有 word 和 sentence | HTTP 统计分别加一，三个页面都显示实际张数。 |
| 有已毕业的单词，但当前没有对应句子卡 | `graduated` 与 `sentence_cards` 可以不同，禁止用一个代替另一个。 |
| 库为空、只有句子或读取到旧版统计响应 | 空库 0/0、有句无词 0/1；缺分项的旧响应展示“共 N 张卡”，不会显示“N 个词”。 |
| 只有跳过、自评或识别错误 | 学习记录显示依据与空态，不显示独立首答错误建议。 |
| dog 的错误建议展示后被删除或修订 | 开始专项得到原目标失效提示，可返回；不会练到另一词。 |
