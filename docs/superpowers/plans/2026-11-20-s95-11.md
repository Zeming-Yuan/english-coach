# 区分自然点单表达与未判定回答 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal** 新买饮品轮次认可已核对的 `A glass of water, please.`，未覆盖回答得到中性反馈，历史规则与首答可以原样回看。

**Architecture** 新增 drinks-v2 规则，保留 drinks-v1 材料与注册映射。角色反馈新材料使用 scene-feedback-v2，备份和验证同时支持 v1/v2，并按每条反馈声明的版本校验。判分继续由本地限定规则负责，AI 仅能选择符合已保存判定的角色回应。

**Tech Stack** Python、JSON 核对材料、SQLAlchemy、FastAPI、React、pytest、Playwright。

**Spec** https://github.com/Zeming-Yuan/english-coach/issues/95 ，B4、B6。候选 11 无业务前置。

```python
from uuid import uuid4


def test_unknown_feedback_is_neutral_and_has_no_correction(ec):
```

```python
FEEDBACK_VERSION = 'scene-feedback-v2'
FEEDBACK_FILES = {'scene-feedback-v1': 'v1.json', 'scene-feedback-v2': 'v2.json'}


def feedback_choices(scene_id, task_key, verdict, skipped, version=FEEDBACK_VERSION):
    material = json.loads((Path(__file__).parents[1] / 'data/scene_feedback' / FEEDBACK_FILES[version]).read_text())
    if skipped:
        return material['other']['skipped']
    if verdict != 'accepted':
        return material['other'][verdict]
    return material['accepted'][scene_id][task_key]
```
