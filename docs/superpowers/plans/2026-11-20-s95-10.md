# 练场景前先学缺词 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal** 学习者可以显式进入当前场景的词汇准备、逐词学习并回到原场景，也可直接挑战。

**Architecture** 场景目录保持不揭示英文答案，只新增「先学本场景用词」行动。显式准备使用本地核对的目标词资料，逐词正反面学习与听读，通过纯读 API 关联已有词卡及修订。未入库词可在准备中学习，但没有隐式建卡。准备状态驻留页面，创建场景继续复用已有 create_scene。

**Tech Stack** FastAPI、SQLAlchemy、React、pytest、Playwright。

**Spec** https://github.com/Zeming-Yuan/english-coach/issues/95 ，B3、B6。候选 10 无业务前置。

## Global Constraints

- 「缺词准备是显式学习动作，不在进行中的独立题面提前揭示答案。」
- 「只有答案实际可见或音频实际开始时才按已有接触规则处理」
- 「仅访问准备页不建卡、不生成作答」
- ADR-0005 和 0008 的独立证据规则继续生效，词汇准备不生成场景通过。
- 与候选 11 对场景服务、目录和浏览器测试的改动串行整合。此关系是文件整合约束，两票均可独立完成业务验收。
- 执行前获取最新 dev 并运行 `.venv/bin/python scripts/agent_check.py --base dev`。

## Review Focus

1. 空词库访问准备后仍零卡、零场景、零作答。任务 1/2 的快照断言。
2. 已有词义被自定义时使用当前卡内容，接触绑定该修订。任务 1/2 测试。
3. 切场景时旧 GET 回包不能串进新场景。任务 2 延迟回包测试。
4. 音频失败不能记录 answer_audio，准备仍可返回。任务 2 测试。
5. 恢复或删除后接触确认过期，不能通过词形猜测新卡身份。任务 2 测试。

## 文件与接口

- 新建 `app/data/scene_vocabulary.json`，按 scene_id 保存核对过的目标词释义及短用法，限已有三个场景的目标词。内容负责人核对，不能由字符串拼接凑释义。
- 修改 `app/services/scenes.py` 新增 `scene_vocabulary(db, scene_id)`，调用已有 `scene_rules` 提取目标词，只读关联已存在单词卡与当前 content_revision。
- 修改 `app/routers/practice.py` 新增 `GET /scenes/{scene_id}/vocabulary`，返回 `{scene_id, title, words:[{word, meaning, example, card_id, content_revision}]}`。不存在场景返回 404。card_id/revision 对缺词为 null。
- 新建 `frontend/src/components/SceneVocabulary.jsx`，呈现词汇正反面、试听、前后导航和返回，不向场景答题泄露标准表达。
- 修改 `frontend/src/views/ScenePage.jsx`，添加准备入口与受当前 scene_id 约束的加载状态，复用 `recordContact` 与 `speak`。
- 新增 `tests/test_s95_scene_vocabulary.py`、`e2e/s95-10.spec.mjs`。
- 不新增 schema 或持久集合。已有卡接触继续写既有 learning_contacts，沿用 V3。

```python
words = list(dict.fromkeys(w for t in rules['tasks'] for w in t['target_words']))
rows = []
for word in words:
    card = next((c for c in cards if c.word.strip().lower() == word), None)
    material = materials[word]
    rows.append({
        'word': word,
        'meaning': card.meaning if card else material['meaning'],
        'example': card.example if card else material.get('example'),
        'card_id': card.id if card else None,
        'content_revision': get_content_revision(db, 'card', card.id) if card else None,
    })
return {'scene_id': scene_id, 'title': rules['title'], 'words': rows}
```

```javascript
import {test, expect} from './support/test.mjs';
test('S95-10 prepare missing words and return without creating cards', async ({app, page}) => {
  const before = await (await app.request.get('/api/export/backup')).json();
  await page.goto(app.baseURL);
  await page.getByRole('button', {name: '场景练习', exact: true}).click();
  const card = page.getByRole('article', {name: '买饮品', exact: true});
  await card.getByRole('button', {name: '先学本场景用词', exact: true}).click();
  const preparation = page.getByTestId('scene-vocabulary');
  await expect(preparation).toContainText('water');
  await preparation.getByRole('button', {name: '查看释义', exact: true}).click();
  await expect(preparation).toContainText('水');
  await preparation.getByRole('button', {name: '返回买饮品', exact: true}).click();
  const after = await (await app.request.get('/api/export/backup')).json();
  expect(after.cards).toEqual(before.cards);
  expect(after.learning_events).toEqual(before.learning_events);
  expect(after.extensions.practice_sessions).toEqual(before.extensions.practice_sessions);
  expect(after.extensions.scene_attempts).toEqual(before.extensions.scene_attempts);
  await card.getByRole('button', {name: '直接挑战', exact: true}).click();
  await expect(page.getByTestId('scene-session')).toContainText('第 1/3 轮');
  await expect(page.getByTestId('scene-session')).not.toContainText('Can I have');
});
```
