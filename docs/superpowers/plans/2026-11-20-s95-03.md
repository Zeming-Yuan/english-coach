**Goal:** 从已加入词详情和原轮完成页主动开始一道新语境练习，保存首答，下一次主动练习有新身份。

**Architecture:** 沿用持久 `practice_sessions` / `practice_items` 与提交事务，增加 expansion 用途和一种冻结的扩展应用题。首版用已核对的本地 apply/application 材料，题目候选不足或义项不匹配返回 unavailable。识别题沿 choice 证据，复用 question token 判分，不把即时辨析记成延迟保持。

**Blocked by:** S95-02。和 S95-05/06 对 practice/quiz 判分、公用 UI 及 V3 共享代码串行整合。

```python
from uuid import uuid4

def test_expansion_practice_has_context_and_new_session(ec):
    source=ec.seed_card('apple',meaning='苹果',related_words=[
        {'kind':'lookalike','word':'apply','meaning':'申请'}])
    source_revision=ec.client.get(f'/api/cards/{source}').json()['content_revision']
    operation_id=str(uuid4())
    added=ec.client.post(f'/api/cards/{source}/expansion-additions',json={
        'operation_id':operation_id,'source_revision':source_revision,
        'target':{'word':'apply','meaning':'申请'}})
    assert added.status_code==200,added.text
    target=added.json()['card_id']
    revision=ec.client.get(f'/api/cards/{target}').json()['content_revision']
    payload={'id':str(uuid4()),'purpose':'expansion','addition_operation_id':operation_id,'source_card_id':source,
      'source_revision':source_revision,'card_ids':[target],
      'targets':[{'card_id':target,'revision':revision}]}
    first=ec.client.post('/api/practice-sessions',json=payload)
    assert first.status_code==200,first.text
    run=first.json()
    assert run['items'][0]['prompt']=='I want to ___ for this job.'
    assert set(run['items'][0]['options'])=={'apply','application'}
    replay=ec.client.post('/api/practice-sessions',json=payload).json()
    assert replay['id']==run['id']
    later=ec.client.post('/api/practice-sessions',json={**payload,'id':str(uuid4())})
    assert later.json()['id']!=run['id']
```
