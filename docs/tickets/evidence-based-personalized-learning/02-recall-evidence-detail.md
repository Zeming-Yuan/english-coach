## 验收条件

- [ ] 服务端从当前内容修订的真实事件生成证据摘要；两次不同学习日首答独立正确且相隔至少 24 小时，才显示回忆已有证据。只有一次则显示仍需验证。
- [ ] 首字母/长度/实时反馈/答案音频等帮助、识别、自评及迁移基线分别解释，不满足独立回忆门槛；三次失败不能显示 100% 掌握。
- [ ] 新独立失败使当前回忆证据待巩固，超过三十天提示待复测，历史成功仍可查看；词义修改后旧证据不证明新修订。
- [ ] 详情并列显示真实 FSRS 到期和证据日期/数量；兼容毕业字段仍表达句子练习解锁。尚无长间隔或应用功能时相应维度为暂无证据。
- [ ] 新写入所需的修订关联、规则版本和可重算依据同步进入 V3；保存失败、失效题与原提交回放不会重复产生或刷新证据。

- [ ] 本票路径的保存失败、重复确认、内容修订/删除及恢复边界有可观察结果；不依赖尚未实施的票兜底。
- [ ] 若引入新的持久记录或用途，本票同步实现 V3 导出、校验、引用映射、恢复及旧格式缺失解释；不能只加表后等待最后集成票。
- [ ] 本票新增具名用户级测试分支并登记到完整覆盖门禁，同时维护受影响的现有场景，不降低原有验收要求。

学习事件与修订关联、统一提交/证据查询 API、独立拼写与词卡详情 UI、可控时钟/失败/恢复测试。

涉及层按完成用户路径所需选择；复用现有 schema 的切片不强制新建表。实现位置由当时仓库结构决定，本票不指定易失效的产品源码路径。

## 验证命令

从仓库根目录运行，Python/前端依赖已安装；以下使用当前 Linux 工作区实际存在的虚拟环境入口，无需系统 `python` 别名：

```bash
.venv/bin/python -m pytest -q
npm --prefix frontend run test:e2e
```

E2E 主入口会重新构建并运行桌面/移动视口。每票只要求本票及前置已交付的分支，新增必跑分支须随本票接入覆盖校验；不预登记未来尚不存在的分支导致前置无法合入。本地 EL 标识不能直接传给当前仅接受 EC-NN 的单票过滤参数。若以后增加定向命令，须先实现并验证拒绝未知/空匹配；完整未过滤门禁仍保留。

这些是本票实施后的验证要求，不是本次文档任务已运行产品测试的声明。

最高测试 seam：浏览器用户操作 → 真实 React → 真实 FastAPI → 真实 FSRS/事务 → 经 Alembic 迁移建立的隔离 SQLite。只替换外部 AI/TTS，时钟在启动处注入；正常成功路径不伪造应用 API。公开 HTTP、迁移、并发和恢复测试补充边界。

## 独立验收方式

1. 在词卡独立输入三次错误，再用辅助/识别/自评答对，详情仍不满足独立回忆。
2. 在同日、跨午夜不足 24 小时、间隔至少 24 小时的不同学习日分别作答，核对边界。
3. 推进时间超过三十天或编辑释义，核对待复测与历史；导出恢复后重读一致。
4. 在本票与所有前置已完成、后继尚未实施的代码状态下执行上述命令，保留真实运行结果、源码/产物身份及失败诊断；按下述方式演练功能回退。

仅依赖本票和其已完成阻塞票即可演示。测试可用隔离夹具准备旧数据和词库，关键成功作答仍从真实入口发生；不得依赖用户数据库或真实付费模型。

## 明确不做

- 不迁移首页、词表、统计或分享图，不实现一周回测、课程短测或场景证据。
- 不把输入速度作为能力信号，不另起 FSRS。
- 本票不自动发布/部署，不扩大为横向框架重写，不使用 LLM 评价替代既有确定规则。

## 回退方式

详情退回真实原始事件与“依据不足”的保守展示，保留证据 API、规则版本和原事件，不恢复按次数计算的 100% 掌握。

共同边界：已新增的学习、上下文、修订与备份数据继续可读；有后继消费者时按依赖逆序撤回，或保留它们依赖的 API/数据适配。功能回退与事务回滚分别验收。不得以恢复旧快照、删除新字段或清空事件来冒充回退成功。

## 规格覆盖与领域约束

- 规格验收条件：AC01、AC03、AC04、AC05、AC06、AC07。属于共享条件时，本票负责自己路径的完整行为，集成票负责跨路径组合，不替本票补实现。
