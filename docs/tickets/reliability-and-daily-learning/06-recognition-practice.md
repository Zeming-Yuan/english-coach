## 用户可观察的行为 / What to build

用户完成看中文选词、听力四选一和相关词题时，得到服务端确认的答案反馈；这些识别练习被记录，但不被当成独立回忆排期。

## 涉及的相关层

题目上下文契约、统一判分/事件 API、测验和听力 UI、异常状态、浏览器/HTTP 测试。

## 验收条件

- [ ] 标准答案由服务端可校验的题目上下文确定；不信任客户端正确下标或客户端直接给出的正误。
- [ ] 相关词题使用相关词标准答案而非原词；缺少有效干扰项时不发出虚假的选择题，低词量仍可完成其他学习。
- [ ] 每次答题只追加一个识别事件、更新一次错词权重，不更新 FSRS；客户端额外评分不能覆盖此策略。
- [ ] 听力与测验都在保存确认后反馈/切题；失败保留选择与标识，跳过记录为空正误且不排期。
- [ ] 空题目、加载错误、TTS 失败与未配置服务分别展示，不把故障显示为正常空队列；原成功响应字段表达真实当前状态。

## 验证命令

在仓库根目录、已安装项目依赖并激活 Python 虚拟环境后执行。E2E 入口及 --ticket 选择由 EC-01 建立；以下是本票交付后必须通过的命令，不是现状通过声明。每票自行注册场景，空匹配必须失败。

```bash
npm --prefix frontend run test:e2e -- --ticket EC-06
python -m pytest -q
```

最高测试 seam：浏览器 → 真实 FastAPI → Alembic 迁移建立的隔离 SQLite。只替换 AI/TTS 外部服务，失败路径可注入传输/事务故障；成功的应用保存和读取不伪造 API。

## 独立验收方式

完成听力与测验选择的正确、错误、跳过；伪造正确下标仍由服务端正确判分；模拟保存失败和 TTS 失败，确认记录/排期和页面行为。

只需要本票及其已完成阻塞票，不依赖尚未完成票补齐本票行为。固定数据通过隔离测试准备，不能以用户数据或真实 AI 作为前提。

## 明确不做

不做输入题或混合页迁移，不实现语音识别/口语评分，不增加新测验类型。

## 回退方式

回退相关 UI 时保留新判分适配和已有识别事件；不将已记录识别结果重新转换成 FSRS 复习。

如后续消费者已经落地，先按依赖逆序回退，或保留公共兼容面并关闭本票入口；任何回退都不能抹除后续新增学习数据。事务故障回滚与版本回退分别验收，不混为一谈。
