学习者可以从全新安装进入每日学习、跨天查看真实进展、备份到另一实例并继续学习；维护者用一条主命令验证完整交付。

## 验收条件

- [ ] 无选择过滤地执行规格 T01–T21，覆盖 420×880 与 1280×720，并验证键盘可达、错误与保存状态的可感知文本。
- [ ] 完整演示入门、每日队列、巩固、跨天统计、旧库升级、下载与恢复到另一实例、继续作答；正常路径经过真实 API/事务/迁移库。
- [ ] 断言失败、空样本跳过、阻塞和流程中断都导致非零退出，留诊断；不调用真实付费 AI或触碰用户数据。
- [ ] 后端回归和前端构建通过，命令自带测试配置；说明配置、学习日、题型规则、备份范围、旧历史限制和恢复入口。
- [ ] 完成一次以隔离真实数据为基础的版本回退兼容演练；确认已有事件不因回退而丢失，记录不能安全降级的边界和前向恢复步骤。
- [ ] 逐项核对父规格 AC01–AC15；只有全部满足才可把整体标为完成，不用本票承接前面票本应交付的功能。

## 验证命令

在仓库根目录、已安装项目依赖并激活 Python 虚拟环境后执行。E2E 入口及 --ticket 选择由 EC-01 建立；以下是本票交付后必须通过的命令，不是现状通过声明。每票自行注册场景，空匹配必须失败。

```bash
npm --prefix frontend run test:e2e
python -m pytest -q
npm --prefix frontend run build
```

最高测试 seam：浏览器 → 真实 FastAPI → Alembic 迁移建立的隔离 SQLite。只替换 AI/TTS 外部服务，失败路径可注入传输/事务故障；成功的应用保存和读取不伪造 API。

## 独立验收方式

新上下文只读本票和父规格，在干净环境运行完整命令并按公开 UI走完双实例旅程；检查失败退出与回退记录，可独立判断交付是否成立。

只需要本票及其已完成阻塞票，不依赖尚未完成票补齐本票行为。固定数据通过隔离测试准备，不能以用户数据或真实 AI 作为前提。

## 明确不做

不重新实施前面票的功能、不补云部署/商业化、不自动发布 issue 或产品。

## 回退方式

本票主要为发行编排、说明和集成断言；撤回它不删除任何业务数据。回退已交付功能按依赖逆序或保留兼容契约进行，不能以旧数据库快照覆盖新增进度。

如后续消费者已经落地，先按依赖逆序回退，或保留公共兼容面并关闭本票入口；任何回退都不能抹除后续新增学习数据。事务故障回滚与版本回退分别验收，不混为一谈。

## 规格覆盖
