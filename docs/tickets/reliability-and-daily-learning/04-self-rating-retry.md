## 用户可观察的行为 / What to build

闪卡，以及课程、故事和词卡详情中的显式评分，只有保存成功才推进；断连、连点和刷新重试不会多记一次。

## Blocked by

- EC-03：Expand：新增学习事件，首次看见真实评分轨迹

## 涉及的相关层

事件唯一约束与提交结果、共享提交模块、显式评分 API、相关页面待保存状态、故障注入测试。

## 验收条件

- [ ] 所有显式记忆评分入口携带稳定提交标识与可辨认来源；评分 1–4 的排期、事件和错词更新原子完成。
- [ ] 相同标识和内容返回原结果；相同标识不同内容返回 409，并发重试同样只生效一次；旧无标识请求保留有限兼容。
- [ ] 保存中锁住重复操作；失败保留当前题、评分和标识，不增加完成数；响应丢失后重试返回已提交结果。
- [ ] 刷新后可从本地待确认提交继续核实，不提供离线自动重放；卡片不存在返回 404，并允许明确放弃失效题。
- [ ] AI 句子升级或 TTS 失败不撤销已提交评分，后台工作不决定页面是否完成。

## 验证命令

在仓库根目录、已安装项目依赖并激活 Python 虚拟环境后执行。E2E 入口及 --ticket 选择由 EC-01 建立；以下是本票交付后必须通过的命令，不是现状通过声明。每票自行注册场景，空匹配必须失败。

```bash
npm --prefix frontend run test:e2e -- --ticket EC-04
python -m pytest -q
```

最高测试 seam：浏览器 → 真实 FastAPI → Alembic 迁移建立的隔离 SQLite。只替换 AI/TTS 外部服务，失败路径可注入传输/事务故障；成功的应用保存和读取不伪造 API。

## 独立验收方式

在闪卡注入保存前失败和提交后丢响应，刷新并重试，确认只产生一次排期和事件；在课程、故事、详情入口各执行一次同类失败/成功路径。

只需要本票及其已完成阻塞票，不依赖尚未完成票补齐本票行为。固定数据通过隔离测试准备，不能以用户数据或真实 AI 作为前提。

## 明确不做

不迁移客观拼写、选择题或混合练习；不新增自动离线同步或云端续接。

## 回退方式

回退页面适配时保留服务端新契约、事件和去重约束，兼容旧调用者。若后续票已消费此契约，不撤除公共提交能力。

如后续消费者已经落地，先按依赖逆序回退，或保留公共兼容面并关闭本票入口；任何回退都不能抹除后续新增学习数据。事务故障回滚与版本回退分别验收，不混为一谈。

## 规格覆盖

T05–T07、T20/T21 的显式评分部分；AC03、AC04、AC11、AC14。
