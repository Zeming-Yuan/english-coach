## 用户可观察的行为 / What to build

用户能分别理解独立提取、提示练习、选择题和闪卡自评结果；未知历史、即时重做或提高每日目标不会虚增新词推荐。

## Blocked by

- EC-05：迁移拼写与填空：一次提交，区分独立回忆和提示
- EC-06：迁移测验选择与听力：服务端判分，识别练习不改排期
- EC-08：跨天历史、热力图和连续学习天数可信

## 涉及的相关层

事件聚合与采样、统计/今日推荐 API、统计与目标说明 UI、样本边界与跨日测试。

## 验收条件

- [ ] 客观题按独立提取/辅助与识别类型解释，正误为空和跳过不入正确率分母；闪卡另显示自评通过率。
- [ ] 无有效样本显示暂无数据；旧基线与未分类旧请求不冒充正确样本。
- [ ] 自适应取近 7 学习日内可排期事件，同卡同日取首次；1–2 分需强化，3–4 分通过。
- [ ] 超过 30% 错误比例推荐 5 个、低于 15% 且样本至少 20 推荐 15 个、其余默认 10；样本不足不自动上调，高错误仍可下调；边界值有确定测试。
- [ ] 每日完成目标与新词配额分开，提高目标不能抵消新词下调；界面显示真实数值，不出现未插值占位符。

## 验证命令

在仓库根目录、已安装项目依赖并激活 Python 虚拟环境后执行。E2E 入口及 --ticket 选择由 EC-01 建立；以下是本票交付后必须通过的命令，不是现状通过声明。每票自行注册场景，空匹配必须失败。

```bash
npm --prefix frontend run test:e2e -- --ticket EC-09
python -m pytest -q
```

最高测试 seam：浏览器 → 真实 FastAPI → Alembic 迁移建立的隔离 SQLite。只替换 AI/TTS 外部服务，失败路径可注入传输/事务故障；成功的应用保存和读取不伪造 API。

## 独立验收方式

经真实提交准备独立、带提示、识别与自评样本，检查不同统计口径；模拟不足样本、阈值两侧和同日重做，查看首页推荐与设置变化。

只需要本票及其已完成阻塞票，不依赖尚未完成票补齐本票行为。固定数据通过隔离测试准备，不能以用户数据或真实 AI 作为前提。

## 明确不做

不训练 FSRS 参数，不新增科学效果承诺，不在本票重排每日流程。

## 回退方式

回退推荐策略或指标显示时保留分类事件；必要时回到固定新词默认值，不把未知记录改成正确来维持旧报表。

如后续消费者已经落地，先按依赖逆序回退，或保留公共兼容面并关闭本票入口；任何回退都不能抹除后续新增学习数据。事务故障回滚与版本回退分别验收，不混为一谈。
