## 用户可观察的行为 / What to build

用户三天复习同一张卡，仍能看到三天活动；上海时间午夜附近的计数正确，重试与同日重复学习不重复计完成词。

## Blocked by

## 涉及的相关层

事件时间/学习日读取、历史与统计 API、词卡历史/统计和首页计数 UI、固定时钟浏览器测试。

## 验收条件

- [ ] 当前完成词数按当天成功排期的不同卡计，练习次数按真实非跳过作答事件计，跳过单列；重复请求不增量。
- [ ] 历史、热力图和 streak 读取事件；至少一次非跳过作答才构成学习日，后续复习不抹去前一天。
- [ ] UTC 存储和事件当时的学习时区归属一致，默认上海；配置变化不重写已归属的历史。
- [ ] 升级前最后活动及累计基线与完整事件区别展示，未知日期不伪造；旧覆盖缺口有提示。
- [ ] 现有公开计数字段与新界面术语保持一致；详情历史与首页/统计页对同一活动无矛盾。

## 验证命令

在仓库根目录、已安装项目依赖并激活 Python 虚拟环境后执行。E2E 入口及 --ticket 选择由 EC-01 建立；以下是本票交付后必须通过的命令，不是现状通过声明。每票自行注册场景，空匹配必须失败。

```bash
npm --prefix frontend run test:e2e -- --ticket EC-08
python -m pytest -q
```

最高测试 seam：浏览器 → 真实 FastAPI → Alembic 迁移建立的隔离 SQLite。只替换 AI/TTS 外部服务，失败路径可注入传输/事务故障；成功的应用保存和读取不伪造 API。

## 独立验收方式

固定时钟跨三天从浏览器给同一卡评分；再做同日两次真实提交和一次重试；检查日历、streak、完成词数与练习次数，覆盖上海午夜。

只需要本票及其已完成阻塞票，不依赖尚未完成票补齐本票行为。固定数据通过隔离测试准备，不能以用户数据或真实 AI 作为前提。

## 明确不做

不在本票完成客观正确率分类、自适应新词策略、每日流程重排或备份。

## 回退方式

回退统计 UI/读取适配时保留事件时间、学习日和迁移基线；不能为恢复旧显示而压缩或覆盖历史。

如后续消费者已经落地，先按依赖逆序回退，或保留公共兼容面并关闭本票入口；任何回退都不能抹除后续新增学习数据。事务故障回滚与版本回退分别验收，不混为一谈。
