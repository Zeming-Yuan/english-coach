## 用户可观察的行为 / What to build

学习者在独立拼写或中译英/填空中提交一次答案，就能获得可靠结果；请求提示后不会把答对记录成独立掌握。

## Blocked by

## 涉及的相关层

作答事件字段、服务端判分与原子提交、拼写/测验输入 API、输入和提示 UI、浏览器/HTTP 测试。

## 验收条件

- [ ] 独立拼写、测验中的中译英与填空经统一模块一次完成判分、事件、错词及必要排期；不再先判分再另发评分请求。
- [ ] 独立回忆提交前不展示目标词、长度提示、首字母、逐字正误或目标词朗读；请求任一辅助后本题标为提示练习。
- [ ] 独立提取答对用 3、答错用 1 更新 FSRS；提示练习保存客观结果但不更新排期；跳过保存正误为空的事件且不排期。
- [ ] 稳定标识、原子回滚、重复请求与失败后停留的语义符合共享提交契约，相关输入不会在保存未确认时解锁下一题。
- [ ] 单词不存在、空输入和规范化边界给出确定结果；仅离开页面不产生作答。

## 验证命令

在仓库根目录、已安装项目依赖并激活 Python 虚拟环境后执行。E2E 入口及 --ticket 选择由 EC-01 建立；以下是本票交付后必须通过的命令，不是现状通过声明。每票自行注册场景，空匹配必须失败。

```bash
npm --prefix frontend run test:e2e -- --ticket EC-05
python -m pytest -q
```

最高测试 seam：浏览器 → 真实 FastAPI → Alembic 迁移建立的隔离 SQLite。只替换 AI/TTS 外部服务，失败路径可注入传输/事务故障；成功的应用保存和读取不伪造 API。

## 独立验收方式

对同一词分别完成独立答对、答错、使用首字母后答对及跳过；经公开查询和页面确认事件分类及排期差异，再注入失败重试。

只需要本票及其已完成阻塞票，不依赖尚未完成票补齐本票行为。固定数据通过隔离测试准备，不能以用户数据或真实 AI 作为前提。

## 明确不做

不迁移听力/看中文选择题或混合练习页面；不新增另一套评分服务或新的学习模式。

## 回退方式

撤回本批页面迁移时保留共享判分接口和事件字段；已记录的独立/提示分类不改写。后续依赖的调用者须先回退或维持适配。

如后续消费者已经落地，先按依赖逆序回退，或保留公共兼容面并关闭本票入口；任何回退都不能抹除后续新增学习数据。事务故障回滚与版本回退分别验收，不混为一谈。
