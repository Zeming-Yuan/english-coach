## 用户可观察的行为 / What to build

混合练习中的拼写、选择和听力复用独立入口规则，失败不自动跳题，选择题不会因两次请求重复加减错词。

## Blocked by

- EC-05：迁移拼写与填空：一次提交，区分独立回忆和提示
- EC-06：迁移测验选择与听力：服务端判分，识别练习不改排期

## 涉及的相关层

复用的题型契约、来源分类与事件提交、混合页面状态、自动切题计时、跨入口浏览器测试。

## 验收条件

- [ ] 各题型复用已交付的判分、提示与排期规则，只补充混合来源；不另算一套客户端最终正误。
- [ ] 移除选择后的重复判分/写入，任何一次答题恰好对应一次事件和一次错词变化。
- [ ] 保存确认后才开始自动切题计时；保存失败或响应未知时停止计时并保留当前题，刷新/重试复用标识。
- [ ] 跳过、空题池、题目不足、加载故障与外部服务失败有明确分支；空题池不冒充已完成。
- [ ] 独立入口和混合入口的同类题在相同输入/提示下产生相同排期效果。

## 验证命令

在仓库根目录、已安装项目依赖并激活 Python 虚拟环境后执行。E2E 入口及 --ticket 选择由 EC-01 建立；以下是本票交付后必须通过的命令，不是现状通过声明。每票自行注册场景，空匹配必须失败。

```bash
npm --prefix frontend run test:e2e -- --ticket EC-07
python -m pytest -q
```

最高测试 seam：浏览器 → 真实 FastAPI → Alembic 迁移建立的隔离 SQLite。只替换 AI/TTS 外部服务，失败路径可注入传输/事务故障；成功的应用保存和读取不伪造 API。

## 独立验收方式

在独立与混合入口使用同样的三种题型逐一作答，比较事件与排期；对混合选择题计一次提交，并在自动切题前注入失败。

只需要本票及其已完成阻塞票，不依赖尚未完成票补齐本票行为。固定数据通过隔离测试准备，不能以用户数据或真实 AI 作为前提。

## 明确不做

不调整题型配比算法，不建立第二套题库或重做所有练习组件。

## 回退方式

隐藏或回退混合页新编排，保留独立入口与共享提交能力；混合来源历史保留。

如后续消费者已经落地，先按依赖逆序回退，或保留公共兼容面并关闭本票入口；任何回退都不能抹除后续新增学习数据。事务故障回滚与版本回退分别验收，不混为一谈。

## 规格覆盖

T05–T07、T10、T11、T20 的混合入口部分；AC03、AC04、AC06。
