# Issue tracker: GitHub

Issues and specs live in Zeming-Yuan/english-coach GitHub Issues.
Use the gh CLI from this repository.

- Read tickets with their comments and labels.
- Publish tickets and specs as GitHub issues.
- Use --body-file for multiline issue bodies and comments.
- Use the label mapping in docs/agents/triage-labels.md.

## Pull requests as a triage surface

PRs as a request surface: no.
