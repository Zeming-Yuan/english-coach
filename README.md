面向零基础英语学习者的 AI 个性化学习应用。核心闭环：**AI 生成词卡 → 间隔重复（FSRS）→ 产出型练习（拼写/听写/测验/混合）→ 情景记忆（语境/故事/记忆法）→ 学习科学持续优化**。全程发音（edge-tts 微软神经语音），本地运行。

## 学习科学设计（本项目的核心亮点）

| 科学原理 | 落地功能 |
|---|---|
| **间隔重复 / 遗忘曲线** | FSRS（py-fsrs）按个人记忆状态排下次复习，desired-retention 思想：近 7 个学习日首答复习通过率自动调每日新词量（5/10/15） |
| **提取练习 (Retrieval)** | 拼写练习（独立回忆或提示辅助）、听写 4 选 1、测验逐题判分 |
| **生成效应 (Generation)** | 释义 → 主动拼写英文，比被动识别记忆深 |
| **错误增强 (Errorful Learning)** | 答错词加权入库（error_cards），优先重现，连续对 2 次减权 |
| **渐褪提示 (Fading Scaffolding)** | 拼写三档：提示首字母 → 提示长度 → 独立回忆；请求提示后不冒充独立掌握 |
| **可理解输入 (i+1)** | 句子意群切分（3-6 词一块）+ 语法角色语义配色 + 逐块点读跟读，先"读得下来"再"看得懂" |
| **脚手架递减 (Fading)** | 中文翻译智能档：复习 <3 次自动显示，≥3 次自动隐藏；也可设置常显/隐藏 |
| **元认知校准 (JOL)** | 翻面前"先回想 3 秒"引导 + 过快翻面提醒，破除流畅性错觉 |
| **双重编码 (Dual Coding)** | AI 例句/故事强制"具体、有画面感、有情绪"（如 "The red apple rolled off the table into the dog's bowl."） |
| **交错练习 (Interleaving)** | 混合练习：拼写/听写/选择随机交错 |
| **自我解释 (Self-explanation)** | 每词可写自己的记忆法（谐音/联想），复习时展示 |
| **预测试效应 (Pretesting)** | 课程学新词先猜意思再揭晓，猜错时"对比冲击"强化记忆 |
| **难度自适应 (Adaptive)** | 近 7 天错误率自动调每日目标（>30% 降 / <15% 升），用户设最低保底 |
| **情绪记忆锚点** | streak、目标环、音效反馈、成绩单分享卡 |
| **睡眠巩固提醒** | 20 点后未学习时提示"睡前复习记忆最牢" |

## 句子学习优化（v2 新增，初学友好）

针对零基础"全英文句子看不懂"的痛点，句子卡全套脚手架：

- **正面中文翻译**：句子卡正面直接显示中文（默认智能：复习 <3 次显示，≥3 次自动隐藏），不用翻面才能看懂
- **意群切分**：长句切成 3-6 词的小块（AI 生成时切分 + 旧数据前端兜底），每块一个"呼吸单位"
- **语法角色语义配色**：🟢 主语 / 🟡 谓宾 / 🟠 状语（AI 生成 role 标记，悬浮显示角色名）
- **逐块点读跟读**：点击任意意群块单独朗读该段，跟读节奏；整句朗读/翻面对照保留
- **难度分级标签**：词卡=基础句（basic），毕业句子卡=阅读句（reading，带 📖 标签）
- **对话体句优先**：毕业句子生成优先 A/B 两人对话（有应答、有人物），正面渲染为气泡对话
- **卡片布局自适应**：句子卡更高（420px），内容溢出可滚动不截断，学习区垂直居中

## 功能全景（79 课迭代）

**核心学习**
- 每日学习：首页“开始今天的学习”一键进入去重主队列，先复习最多 20 张到期词，再学建议配额内新词；同组内错词/困难词优先，未到期标记词不自动重播
- 本轮目标开始时固定；保存确认后才推进，刷新后可继续本轮。剩余到期张数单列，完成后可再开一轮
- 每日最低完成目标、新词配额和本轮实际张数分别展示；专项测验、听写、拼写、混合及课程收纳至“专项练习”
- 课程式学习：AI 20 级递进（音标启蒙 → 高频词 → 简单句 → 场景对话）
- 闪卡学习：翻面对照 + 自动发音 + 意群/中文辅助 + 评分（忘了/模糊/记得/太简单）
- 句子练习解锁：复习 3 次或进入复习状态 → 例句自动转句子卡（对话体、阅读句）继续学；解锁不等于掌握

**产出型练习**
- 拼写练习（提示首字母 / 提示长度 / 独立回忆三档；独立输入不提前显示答案，回车提交）
  - 独立答对/答错才更新 FSRS；请求任一首字母、长度或逐字反馈后，本题按带提示记录且不排期
  - 跳过保存为“未作答”事件（正误为空），不增加错词，也不更新排期
- 听写练习（播发音 4 选 1）
- 测验（中译英×3 + 选词 + 填空，逐题判分、错题汇总可点进详情）
- 混合练习：三题型随机交错，复用独立拼写与识别题的判分、提示和排期规则；保存确认后才切题，跳过单独记录并在完成页列为待巩固。题量不足仍可练，空池与加载故障分别提示。未确认提交在重新进入混合练习时可用原标识继续确认。
- 识别练习（听写 4 选 1、测验选择题、相关词选择）由服务端按签名题目上下文判分并记录识别事件，**不更新 FSRS 排期**。题目上下文默认 24 小时有效：页面停留过久或服务重启后提交会返回 409 并要求重新加载题目；篡改上下文或提交选项外答案返回 422，刷新题目即可继续。

**内容与记忆**
- 故事模式：AI 用已学词编故事，整句朗读 + 点词弹卡评分
- 语境例句：两句对话体气泡（可"换一个"）
- 自我记忆法（谐音/联想/小故事）

**单词本**
- 搜索（词/释义/例句中文）+ 相关性排序（完全匹配>前缀>包含>释义>例句）+ A-Z 排序导航 + 右键快速查阅
- 详情页：意群切分/难度标签/学习记录（逐次评分轨迹，升级前旧数据标注“历史记录不完整”）/句子练习解锁状态/错词数/困难词标记/例句发音
- 回忆证据：只按当前内容修订的独立输入首答计算；两个不同学习日且相隔 ≥24 小时才显示“独立回忆已有证据”，新错误转“仍需巩固”，超过 30 天“历史证据，待复测”；辅助/识别/自评/跳过不冒充独立回忆，不再按复习次数显示掌握百分比
- 编辑/删除词卡（AI 生成错了可纠正）；句子长句自动换行不截断

**学习统计**
- 今日目标环（每日目标可设 5/10/15/20）、🔥 streak、错词入口
- 今日完成词（按卡去重）、练习次数、跳过数分列；同一张卡跨天活动保留
- 学习日按 `LEARNING_TIMEZONE`（默认 `Asia/Shanghai`）归属，事件写入时固定，改设置不重写历史
- 指标分列：独立提取 / 辅助练习 / 识别练习 / 自评通过率；无有效样本显示“暂无数据”，自评不冒充客观正确率
- 学习证据聚合：独立回忆已有证据 / 仍需巩固 / 历史证据，待复测 / 独立证据不足 / 历史依据不完整分列，附独立样本数与最近证据日期；句子卡不计入词卡的证据计数
- 新词建议单独计算（近 7 学习日、同卡同日首答）；提高每日完成目标不会抬高新词配额
- 本周复习通过率 + 8 周趋势柱状
- GitHub 风格热力图（最近一年，hover 显示日期与学习时区）；存在旧基线时标注“部分旧历史不可还原”
- 🏅 成绩单分享卡（canvas 生成，展示导出时的解锁数与独立证据样本/日期，可存图进简历）

**数据与设置**
- 💾 设置 → 备份与恢复：下载 V3 版本化完整备份（词卡全部字段、当前记忆状态、学习事件及其修订关联、迁移基线、内容修订、记忆法、错词、困难词、课程、故事及关联）；不包含 API 密钥、环境配置、语音缓存和浏览器偏好。选择文件后可预览新版全量替换或旧版部分恢复，再明确确认执行
- 🧾 内容修订：编辑词形/释义/例句/语境后版本递增，仅改排版或记忆法不增加；词卡详情核对当前修订，备份恢复后继续沿用同一身份
- 🎴 Anki CSV 导出（UTF-8 BOM，无缝沉淀到你现有的 Anki 复习流）
- ⚙️ 设置：发音速度 / 每日新词量 / 中文翻译档位（智能/常显/隐藏）/ 暗色模式
- 新用户 5 分钟闭环：生成词后"马上学一学"不等明天

## 快速开始

```bash
# 1. 创建虚拟环境并安装依赖
python -m venv .venv
source .venv/Scripts/activate        # Windows Git Bash（PowerShell 用 .venv\Scripts\Activate.ps1）
# Linux / macOS：source .venv/bin/activate
pip install -r requirements.txt

# 2. 配置（复制模板；LLM_API_KEY 可留空，本地功能照常可用）
cp .env.example .env
# 编辑 .env：LLM_API_KEY=sk-xxx（可选）、LLM_BASE_URL、DATABASE_URL、LEARNING_TIMEZONE

# 3. 初始化/升级数据库
#    - 迁移与应用读取同一个 DATABASE_URL
#    - 已有库升级前会自动生成副本：<库文件名>.bak-<UTC 时间戳>（与库同目录）
python -m alembic upgrade head

# 4. 启动（8001 是专有端口；8000 常被 WSL 占用）
python -m uvicorn app.main:app --reload --port 8001

# 5. 浏览器打开 http://localhost:8001
```

> **从旧配置迁移**：旧版模板使用 `DEEPSEEK_API_KEY` / `DEEPSEEK_BASE_URL`，现已统一为
> `LLM_API_KEY` / `LLM_BASE_URL`。若同时存在新旧变量，应用会明确报“配置冲突”；
> 若只有旧变量，会提示改用新名称。错误信息不会输出密钥值。
>
> **没有 AI 密钥时**：首页、已有词卡、复习与备份等本地功能可用；调用 AI 生成词卡、
> 课程或故事时返回 HTTP 503，并提示配置 `LLM_API_KEY`。旧故事的自动补翻属于可选增强，
> AI 未配置时仍按原文展示。
>
> **体验入门词卡**：首页空态或「加词」页的「体验入门词卡」按钮会一次性加入 10 张
> 随应用分发的入门词卡（已核对音标、中文释义、完整例句及中文），无需 AI 即可开始学习。
> 该操作是显式的：只添加尚不存在的单词卡，同词自定义内容与句子卡保持原样，重复点击
> 不会重复创建；升级或首次打开应用都不会自动给词库填充内容。内容核对记录见
> `app/data/README.md`。
>
> **数据库不可写**时迁移会说明具体地址与原因（隐藏口令），不会静默失败。升级前备份
> 使用 SQLite backup API 并做完整性校验，校验失败即停止迁移。
>
> **升级前的学习历史**：旧版只保存每张卡最后一次复习状态，无法还原逐次作答。升级会保存
> 旧行的原始基线，词卡详情只展示最后一次可知活动与累计次数，并明确标注“历史记录不完整”；
> 不会按累计次数补造过去日期或正确率。升级后产生的新评分逐条追加，不再覆盖旧记录。
>
> **保存确认与刷新恢复**：闪卡、课程、故事与词卡详情中的每次显式评分，只有服务端确认
> 保存后才推进、关闭面板或增加完成数。保存失败会停留在当前题并保留本次评分，可
> 「继续确认保存」重试同一次提交（不会重复排期或重复记事件）；刷新后若仍有未确认提交，
> 首页会提示继续确认或明确放弃。浏览器本地存储不可写时，待确认请求只保留在内存中，并
> 提示“本次操作尚未确认保存；刷新后可能需要重新核对”。应用不提供离线自动重放：未确认
> 的评分不会被当作已完成。卡片已删除时保存返回 404，可明确放弃失效题。

> 前端开发：`cd frontend && npm install && npm run dev`（Vite dev server，API 代理到 8001）
> 生产构建：`cd frontend && npm run build`（输出到 `app/static/`，FastAPI 直接挂载）

> 首次使用：点首页「体验入门词卡」零配置开始第一轮学习；或进「加词」页输入几个单词（如 `apple, banana, teacher`）→ 点"马上学一学"立即开练；或从「开始零基础课程」走 20 级递进。

## 测试

```bash
# 后端回归：自带占位配置与隔离数据库，不要求真实密钥
python -m pytest

# 浏览器验收（首次需安装前端依赖与 Playwright Chromium）
npm --prefix frontend ci
npm --prefix frontend exec -- playwright install chromium-headless-shell

npm --prefix frontend run test:e2e -- --ticket EC-01   # 只跑本票已交付场景
npm --prefix frontend run test:e2e                     # T01–T21 双视口完整门禁
npm --prefix frontend run build                        # 生产构建
```

- 每次 E2E 使用本次运行独有的临时数据库、端口与构建目录；结束时关闭测试进程。
- 补充 pytest 包装器的 SIGTERM/SIGINT 中断清理已在 Linux 验证：停止所属进程组、回收 pytest，保留非零中断日志。Windows 强制终止路径未做原生验证；Python 信号处理器不能捕获 `TerminateProcess`，不据此承诺所有操作系统的中断清理。
- `--ticket` 接受 `EC-NN` 或 `EL-NN` 形式；未知票号或没有匹配用例会以非零状态退出，不能当作通过。
- 主命令从实际 Playwright JSON 结果逐分支核对 T01–T21；两个项目都必须通过。缺场景、跳过、失败、阻塞、中断或失败后重试都返回非零。`--ticket` 仅用于开发定位，不是整体验收。
- 主命令每次保留 `e2e/release-results/<run>/`：`run.json` 含源码 HEAD、工作区状态、源码内容摘要、构建时间及产物摘要，`playwright.json` 与 `artifacts/` 保存同次运行的报告、trace、截图和补充 HTTP/进程 JUnit 证据。测试临时库与服务器在结束后清理；直接运行 Playwright 的默认诊断仍在 `e2e/test-results/`。这些目录已加入 gitignore。
- E2E 的 AI 与 TTS 提供方使用可控替身（含成功、超时和失败），正常学习和恢复仍经过真实 API/事务/迁移库，不使用真实付费 AI 或用户数据库。完整命令还执行具名 HTTP/安装边界测试，并核对实际 JUnit 参数用例，不能用跳过或空样本充数。
- [发行证据与 AC01–AC15](docs/release-evidence.md) 区分单票验证与最终集成门禁；[版本回退兼容边界](docs/release-compatibility.md) 说明真实旧版只读范围与前向恢复。
- 旧的 `node e2e_test.js` / `node e2e_story.js` 依赖本机 Edge，仅保留作手工调试；自动验收以
  `npm --prefix frontend run test:e2e` 为准。

## 开发规范

- 分支：`main`（稳定）← `dev`（开发）← `feature/xxx`；提交用 Conventional Commits
- 前端静态资源改动后：`index.html` 里 `?v=N` 版本号必须递增（防浏览器缓存）
- `.env` 永不入库（安全红线）；模型名统一走 `app/services/model_router.py`
- 卡片类型（kind）与难度（difficulty）由系统决定，AI 输出不能覆盖

### 换设备恢复完整备份

1. 在原实例打开「设置 → 备份与恢复」，点击「下载完整备份」。
2. 在目标实例同页选择 JSON 文件。当前 V3 显示「全量恢复」、备份格式、各类内容数量和将替换的目标数量；V2 或缺少新增集合的早期 V3 会明确提示缺少内容修订及替换影响。确认前不写入，取消保留原数据。空备份会明确警告替换为 0 项。
3. 核对后点击「确认替换学习数据」。现有数据库学习内容会全部替换，备份未包含的内容会删除；无版本号旧文件仍仅部分恢复其中包含的内容，并为新增卡建立新的修订身份。
4. 只有事务提交后显示恢复成功，并显示数据库旁 `backups/before-restore-*.json` 安全副本的位置。安全副本长期保留，可同样通过文件选择恢复。保存副本失败或写入失败均保留原数据。
5. 出现 409 表示预览后有新学习进度，请重新核对影响范围再确认。响应失联时恢复尚未确认，请重新读取当前数据并预览后决定；不要连续重复替换可能已新增的进度。

恢复保留同词不同卡型、全部状态/事件/内容修订与提交去重。数据库内部 ID 会重新映射；词卡 ID 在空恢复和重启后也不会复用，恢复前启动的后台响应同时校验内容与修订身份，不会覆盖恢复内容。V3 恢复保留内容修订身份与版本；V2/V1 恢复为新增内容建立新身份。已保存提交可用映射后的卡 ID 和原提交标识重试，不重复排期。备份不含 API 密钥、运行配置、题目签名密钥或浏览器偏好。恢复成功后可继续评分与编辑。

当前记忆状态每张卡最多一行；升级会先保留旧重复行的完整基线再收紧唯一索引。旧详情历史、评分 URL、旧部分恢复与 V2 全量恢复继续可用，基线不会冒充作答或提高正确率。V2 同一卡的重复当前状态在预览和执行前均返回 422；迁移降级只撤约束，保留事件、归档与词卡 ID 退役高水位。

### 应用内接触记录

词卡详情和词表只在实际显示、或答案语音真正开始播放后，才向 `POST /api/learning/contacts` 确认一次接触；预取、语音预热、未进入视口的卡片和失败播放都不算。服务端记录目标卡、当时的内容修订、来源与服务端确认时间，不接受客户端回填日期。

闪卡翻面、拼写/测验/听写/混合练习显示答案或实际播放答案语音，也会按同一接口记录接触；题内一旦请求提示，之后关闭提示、切换页面或恢复同一待确认题仍按辅助作答，新抽取题从独立开始。

接触不是作答：不会写入 FSRS 排期、正确率、连续学习日或每日完成，重复确认按提交标识去重。详情“最近应用内接触”显示时间、来源、观察方式与当时修订；没有记录时显示“旧数据未记录，保持未知”，不宣称从未接触。待确认的接触只保存在浏览器 `ec.contact.*` 键，不会被评分恢复界面误当作学习提交；保存失败或本地存储不可用时，详情明确提示“接触依据不完整”。课程与故事阅读按正文实际出现的目标词记录接触；句子朗读实际开始后才记录答案语音，点词显示释义时记录该目标词。故事自动补翻晚到时会校验内容修订，已编辑或恢复的故事不会被旧翻译覆盖。

接触记录随 V3 完整备份导出和恢复。

### 课程进度

课程数量只表示已生成内容，不代表学完。课程详情显示本课目标和学习状态；打开、点“内容已看完”浏览与后续检查分开记录，只有点击“内容已看完”才记录浏览时间（服务端确认、重复提交幂等）。尚无短测时显示“待检查”，不伪造通过；二十课全部生成也只显示已生成，不显示已学完。生成课程会先校验唯一词形、释义、例句翻译与对话配对，词卡、课程和生成状态在同一事务保存；失败不留下半课或跳级。课程状态随 V3 完整备份导出和恢复。

### 课程短测

课程详情可开始本课短测：最多三道不同目标词，少词按实际数量；优先选尚无独立回忆证据的本课词。测试只显示释义，不显示词表、答案、长度或播放答案语音；请求首字母提示后本题持续按辅助记录，刷新或回看课程不会清除。每题首答关联真实学习事件：全部实际题目首答无提示正确才通过，错误或辅助为待巩固，整轮跳过为未完成且不改写课程检查计数。可以只练薄弱项或新开一轮，即时重试不覆盖首次结果；刷新后继续同一轮。轮次、冻结题目与首答事件关联随 V3 完整备份恢复。

### 每日学习的有限巩固与反馈

每日主队列保存后，可为本轮低分、答错或跳过词做最多三道输入巩固题，也可点击「跳过本轮巩固」直接查看结果。刷新可以继续本轮；已保存题不重新发出，不会补进第四题。无薄弱词或无有效题时直接读取本轮结果。

完成页只使用已保存事件：完成词数按成功排期的不同卡片去重，主队列与巩固次数分列，独立提取、辅助练习、识别练习、自评和跳过分别展示。辅助或识别答对不会清除“仍需复习”；后续独立答对或明确高分才清除。下一步来自真实已有排期；本轮完成不保证不会遗忘。跳过整个巩固阶段不产生虚假作答。课程、故事与专项练习仍是补充入口，课程生成不计每日完成。

只读接口：`GET /api/sessions/{session_id}/reinforcement` 与 `/summary`；未知会话返回 404，读取结果不会新增事件。巩固保存失败保留同一待确认提交，确认前不进入结果页；语音或 AI 故障不撤销已保存进度。

每日轮次的冻结队列与巩固候选 ID 只保存在当前浏览器，完成数仍由服务端已保存事件决定；它们不是服务端持久会话表，也不包含在数据库备份。会话只读 HTTP 接口从当前仍存在的事件识别会话、选出最多三个候选；删除词卡会级联删除关联事件，独立 HTTP 调用的候选可能变化，全部事件被删后返回 404。浏览器本轮保留初始巩固槽位，删除卡不会被算作已保存，也不会补入第四题。

新版完整备份的学习事件数组按事件时间及同时间的实际保存次序导出，恢复按数组次序写入；其他集合仍按 ID 导出。事件次序影响本轮反馈，备份修订校验也保留该次序。之前已经按随机事件 ID 排序导出的旧文件可能丢失同一时间内的原始先后；恢复只能保留文件现有次序，不能反推或伪造丢失的次序。

### 学习日与题型规则

新事件保存 UTC 时间及当时的学习时区，默认 `Asia/Shanghai`；之后改时区不会重分过去学习日。同卡同日多次真实作答增加练习次数，成功排期的完成词只算一次，重试不增加任何计数。

| 练习 | 排期及反馈口径 |
| --- | --- |
| 闪卡/课程/故事/详情的显式 1–4 分 | 更新 FSRS；显示自评通过率 |
| 无提示独立拼写/填空 | 答对采用 3、答错采用 1；显示独立提取结果 |
| 首字母/长度/逐字反馈/答案可见或朗读辅助 | 保存辅助结果，不更新 FSRS |
| 四选一/听力/相关词识别 | 保存识别结果，不更新 FSRS |
| 显式跳过 | 正误为空，不排期；跳过单列 |
| 只打开/离开/播放发音 | 不产生作答事件 |

混合入口沿用对应题型规则。复习通过率使用可排期事件，同卡同日首答进入新词建议；无有效样本显示“暂无数据”，未知旧历史不冒充正确答案。新词建议采用近七日样本：高错误率下调为 5；至少 20 个样本且错误率低于 15% 才上调为 15，其他默认 10。每日完成目标不会抬高新词配额。

### 隔日与一周回测（EL-09）

首页或学习统计可开始最多三题的中文释义→英文输入回测，刷新继续同一轮。
“距应用内上次记录”按真实 UTC 时长计算：隔日 `[24,72)` 小时，一周 `[7,14)` 天，
其他时长单列。提交前在另一页看/听答案会重新分类；不推迟正常 FSRS 复习。
统计分列独立成功/样本、辅助、跳过、覆盖词数及实际间隔，同词同学习日同窗口首测
不被重做覆盖；零样本显示暂无数据，不足十个提示样本较少。旧记录不足可进入普通练习。

轮次、依据、提示和首测关联随 V3 完整备份保存，恢复不制造新成功或重复排期。
功能回退只隐藏回测入口，保留数据和恢复兼容，详见 ADR-0002、ADR-0005。
开发定位支持 `npm --prefix frontend run test:e2e -- --ticket EL-09`；
未知票号/空匹配仍失败，未过滤的完整覆盖入口保持不变。
回退演练：设置 `DELAYED_RECALL_ENABLED=false` 并重启，检查首页/统计不再显示回测按钮，
统计仍显示原样本，V3 导出保留轮次/题目/事件，普通练习仍可保存；重新设为 true 恢复入口。

### 从统计进入建议练习（EL-10）

首页和学习统计中的“建议练习”按最近独立首答失败、只有辅助成功、合格延迟候选的顺序，
提供最多三项、每项最多三个词的建议。同词去重；显示中文释义、样本量和相关课次，
不足十个独立样本时说明依据有限。没有样本不解释为能力不足，识别题错误不充当独立提取失败。

点击“开始建议练习”才启动专项或对应窗口的回测；读取建议不改变到期。轮次绑定原词集合、
题型和修订，删除、修订或间隔变化会说明原目标不可用，不换词补题。延迟建议提前隐藏英文；
显式展开后，实际可见的答案记录接触并重算资格。课程列表与详情分别展示本课短测和
当前目标修订上的真实隔日/一周回测，不以全站结果或生成数量推定本课通过。

创建与作答失败可继续确认，刷新后在建议区“继续建议练习”；已保存提交仍按原标识确认。
V3 保留专项轮次/题目和引用映射，恢复后可继续；旧备份预览明确说明没有专项记录。
`LEARNING_ADVICE_ENABLED=false` 可隐藏建议入口，保留已存证据、轮次、真实排期及 V3 兼容读取。

本票定向验证：`npm --prefix frontend run test:e2e -- --ticket EL-10`，同时运行移动/桌面视口；
完整未过滤门禁继续登记 EL10 的十七个具名分支。验收范围及未验证项见
[EL-10 验证记录](docs/verification/el10-actionable-learning-advice.md)。

### 根据回忆依据生成短故事（EL-11）

故事入口选择一至三个当前有效独立回忆依据词；只有明确勾选同意才加入最多一个新目标，不自动添加词卡。基础支撑词表独立标注为教学材料，未覆盖词形逐个显示。标准正文 40–70 词、每句最多 12 词，标题/题干/选项也检查词形及句长，未覆盖词形最多两个。词形覆盖不保证理解全文。

依据不足可直接阅读核对过的入门故事。非法生成最多修正一次；AI 未配置、失败或保存未确认时保留原故事，可使用原操作标识继续确认保存，刷新后仍可确认。旧故事继续可读，缺题显示“本篇暂无检查题”；新理解题材料按版本保存，作答由后续票提供。

V3 同步保存故事版本、固定题目材料与生成去重标识；恢复映射故事关联，旧 V2/早期 V3 明确说明缺少故事版本，不补题或造成绩。删除故事后原操作返回 410，不复活故事。

回退：设置 `BOUNDED_STORIES_ENABLED=false` 并重启，隐藏新生成并返回 403；旧故事、新版本、V3 导出恢复仍可使用。重新开启恢复入口，不删除迁移和学习数据。见 [ADR-0007](docs/adr/0007-bounded-learning-content.md)。

定向验证：`npm --prefix frontend run test:e2e -- --ticket EL-11`；本票具名分支登记于完整覆盖校验。

### 简化故事并保留原版（EL-12）

打开已校验的原版后点“更简单”，生成 20–40 词、每句最多八词的独立简化版；目标词、中英配对、理解题与最多两个未覆盖词形继续校验。原版与简化版均保留，可明确切换，列表标明版本。各版没有检查记录时如实显示“未检查”，读后检查按当前版本独立保存，词卡自评分不算故事成绩。切换后只有实际展示的当前版本记录词卡接触；预取不算。

简化操作在请求前保存稳定标识。生成或保存失败时保留正文，刷新后重开原版可“继续确认保存”；同操作不会重复保存。请求期间切回原版、返回列表或换页，晚到响应不会夺取当前选择。删除原版后已存简化版仍可读；父版本墓碑保留，旧操作不会复活原版。原版或词卡已修订、删除、恢复或依据过期时，未保存请求明确失败，需重新获取有效原版。

V3 导出、校验与恢复包含 `mode`、`parent_version_id`、固定题目和操作标识，UUID 关联保持稳定，内部故事 ID 重新映射。非法父引用或版本环在预览时拒绝。EL-11 的旧 V3 缺这两个字段时解释为原版、无父版本；更早 V3/V2 缺故事版本时仍不补题或成绩。

功能回退：设置 `SIMPLER_STORIES_ENABLED=false` 并重启，隐藏简化入口，POST 返回 403；两版阅读、切换、V3 导出恢复继续保留。恢复 true 可重新开启；不降级迁移、不删列或清空数据。定向双视口验收：`npm --prefix frontend run test:e2e -- --ticket EL-12`；完整覆盖门禁已登记本票具名分支。

### 故事读后检查（EL-13）

有版本的故事提供“读后检查”：最多一题阅读理解选择和一题目标词输入，按实际题数显示。
输入时隐藏原文与目标词；回看或提示必须先确认保存帮助，本题随后按辅助记录。
理解选择只记录阅读识别，辅助输入不排期；独立输入沿用现有 FSRS 规则。
结果保留首次作答，显示原故事版本和阅读识别/词汇独立/辅助数量。即时正确不代表延迟保持，
阅读次数不算每日词卡完成量；旧故事没有题仍可阅读。

保存失败或响应丢失后可以继续确认，刷新后重新打开故事会恢复原检查；V3 恢复到另一实例
同样保留版本、帮助和结果。修订/删除后不接受旧题的新答案，可回到原文或明确放弃待确认。
`STORY_CHECKS_ENABLED=false` 关闭新入口和新轮次，保留全部历史、原文与 V3 适配。
定向验证：`npm --prefix frontend run test:e2e -- --ticket EL-13`；分支已登记到完整覆盖门禁。

## 三轮买饮品文字任务（EL-14）

首页“场景练习”→“买饮品”，先看中文任务、目标词准备状态，再用文字请求水、说明一杯、礼貌确认并致谢。未配置 AI 也使用核对过的角色模板完成三轮。规则认可、明确不满足、未判定与显式跳过分别展示；可请求任务提示/标准表达或再练，首答与帮助持续保留。三轮处理完成不等于独立通过。

只有三轮独立首答全部认可，且与已存教学例句和同任务模板不同的显式目标才获得指定语境应用依据。场景任务不改变 FSRS、词卡完成量或连续学习日。刷新可继续；提交失败保留答案与原标识，必须确认后才推进。V3 包含规则、任务、首答、帮助及应用依据，导入另一个实例可继续；旧备份显示没有场景记录。

`SCENES_ENABLED=false` 重启后关闭新启动，已有记录、原创建确认、V3 读写继续保留，应用摘要显示历史证据；恢复 true 可重开。不执行破坏性 downgrade。见 [ADR-0008](docs/adr/0008-bounded-scene-evidence.md)。

定向验收：`npm --prefix frontend run test:e2e -- --ticket EL-14`；具名分支同时登记在未过滤覆盖门禁。下载测试浏览器受限时，可以设置 `EC_CHROMIUM_EXECUTABLE` 为已安装 Chromium 的绝对路径再运行同一命令；报告记录实际浏览器版本及文件 SHA-256，全部断言、双视口、新构建和源码指纹检查保持启用。默认仍使用 Playwright 配套浏览器。

### 自我介绍与问路（EL-15）

“场景练习”提供买饮品、自我介绍、问路，各自固定三轮并分别恢复最近一次轮次。自我介绍练习姓名、来自地点与喜欢茶，姓名/地点仅作槽位；问路仅练习虚构广场到车站及路口左转，不提供真实导航。每个场景先展示中文目标与词汇准备状态，三轮首答独立认可才表示本场景通过，不代表综合英语水平。规则认可、拒绝、未判定、帮助、跳过和再练沿用 EL-14；V3 保留场景身份、任务和提交回放。

回退 EL-15 可设置 `SCENE_EXPANSIONS_ENABLED=false` 并重启：仅关闭自我介绍/问路的新轮次，买饮品继续可用，已有新场景能继续、导出及恢复；相关应用结果显示历史证据。恢复 true 可重新开启。`introduction-v4` 保留姓名/地点槽位边界，旧 v1–v3 材料与判定仍可恢复；规则修订后旧轮次停止新作答，原提交确认不受影响。

### 保存后的场景回应（EL-16）

首答确认保存后，页面单独获取简短角色反馈；生成期间仍可下一轮。可展开每轮“首答与反馈”查看原答案、规则结果及模板/模型来源。反馈只表达已保存的结果，每轮至多一个冻结任务的关键纠正；未判定保持未判定，不评分或改动 FSRS。未配置 AI、网络故障或输出越界时使用核对模板。实际可见的回复词形按现有接触接口记录，折叠内容与后台生成不算接触。

模型复用现有客户端与任务路由；只收到当前场景材料、可用词形和已存首答结果。回应必须属于 `scene-feedback-v1` 对应任务与结果的有限表达集合，词汇、标准应答泄露、情境或格式校验失败都降级。反馈操作按稳定标识确认，场景、题目、首答和规则版本随 V3 导出恢复，旧格式缺少反馈时不会补造。

定向验收：`npm --prefix frontend run test:e2e -- --ticket EL-16`。执行范围与证据记录在 [EL-16 验证记录](docs/verification/el16-bounded-ai-scene-feedback.md)。

功能回退：设置 `SCENE_FEEDBACK_ENABLED=false` 并重启，仅关闭新模型调用，继续提供核对模板；已保存的模型回应、首答、场景结果和 V3 读写保留。恢复 true 可重新启用，无需清库或降级迁移。旧请求在内容修订、删除或全量恢复后重新核对归属；恢复隔离令牌每次重建，不能用原快照复活旧模型写入。

### 每日时间预算（EL-17）

首页默认约 8 分钟，可在开始前选择约 3/8/15 分钟。按复习 20 秒、新词 40 秒、
巩固每题 20 秒与固定 15 秒开销估算，预留最多三道巩固的时间；估计不是强制倒计时。
到期词优先，每轮至多二十张，仍有到期未纳入时不加新词。今日新词余量按首次真实
排期的不同新卡扣减，迁移基线不占新词额度；继续多轮不会重领完整配额。

开始后卡序和目标冻结。确认保存后可选“先到这里”查看已保存的本段结果，未作答题
仍为未完成，不计跳过；返回首页或刷新后在同一浏览器继续原轮次。保存中或未确认时
先处理原提交，预算到时只提示，不取消请求或缩小目标。词卡修改/删除后旧题会提示
冲突/不存在，可退出本轮重新加载；已保存的相同提交继续幂等回放。

预算偏好和当前轮次只保存在浏览器，完整备份不承诺跨设备继续原每日队列；已保存
事件及其修订前置条件随 V3 备份恢复。旧文件缺少前置条件时保留原事件语义。
功能回退可隐藏预算选择，让新轮次使用默认八分钟，保留原轮次、待确认提交和配额计算。

运行时可用 `TIME_BUDGET_ENABLED=false` 关闭预算选择，新轮次使用默认八分钟；
原浏览器轮次、确认流程、全日余量与 V3 读写仍保留。重新启用后可再次选择预算。

### 个人主动用时估算（EL-18）

每日词卡与巩固的真实作答确认后，会单独保存主动操作时长。后台时间、超过 30 秒的
连续无操作间隔及保存等待不计入；刷新未保存题不会推测旧时长。每类至少五条可靠记录
后，未来预览使用最近三十条中位数（每条按 2–180 秒估算），否则标明默认值及样本不足。
开始后的轮次保留原目标；耗时不会改变判分、回忆证据、FSRS 或完成数。

时长保存失败可“继续确认时长”或明确放弃，答案按原流程保存，不重复评分；待确认身份
保留在当前浏览器，存储不可用时刷新可能丢失。V3 完整备份包含时长、真实提交关联与
规则身份，恢复后可继续校准；旧备份缺失会在预览解释。预算偏好和每日轮次仍属于浏览器。

功能回退：设置 `PERSONAL_ESTIMATES_ENABLED=false` 后重启，仅让预览使用有标注的
默认估算，保留全部时长、答案和 V3 适配。定向双视口验证使用
`npm --prefix frontend run test:e2e -- --ticket EL-18`，具名分支已登记到完整覆盖校验。

### 中断后恢复学习（EL-19）

距最后已保存的活跃学习日达到三天且有到期词时，首页可选择“恢复学习”：约三分钟、
至多五张到期词、本轮零新词。也可继续选择常规计划；仅打开首页不算学习。
保存后可暂停、刷新继续同一轮，结束显示本段保存量及剩余到期，不要求清空积压，
不重置既有 FSRS。无真实活动历史或没有到期词时不制造恢复任务。

功能回退：设置 `RECOVERY_MODE_ENABLED=false` 并重启，隐藏推荐并拒绝新恢复预览；
已开始轮次仍可继续/退出，事件和 FSRS 保留。恢复模式只接受三分钟预算，常规
预算偏好不会被覆盖。定向双视口验证：
`npm --prefix frontend run test:e2e -- --ticket EL-19`。

验收映射、运行身份和未验证门禁见 [EL-19 验证记录](docs/verification/el19-return-to-learning-mode.md)。


### 内部证据与 V3 契约（EL-20）

证据、实际接触与句子练习解锁使用既有统一规则；复习次数不代表掌握。
V3 集合在统一 registry 登记，导出、校验和恢复共用；未知功能、重复声明或漏集合明确拒绝，
早期 V3、V2/V1 的缺失仍在预览中解释。恢复同时间接触保留原保存次序，旧已保存请求回放不刷新证据。
公开 URL、旧事件/基线和毕业兼容字段保留。具名双视口验收：
`npm --prefix frontend run test:e2e -- --ticket EL-20`；[消费者与验证边界](docs/verification/el20-contract-evidence-consumers.md)。

EL-20 恢复预览逐项显示缺失的新集合；完整替换展示恢复 0 项与当前被替换量，旧部分恢复说明保留现有记录。只缺某集合时不误报已包含的修订会重建。

EL-21 集成资格：新增新装、旧库升级、V3 换设备续学和故障保护旅程，连同全部既有分支在

定向开发验证仍使用 `npm --prefix frontend run test:e2e -- --ticket EL-21`；
定向成功不代表完整发行资格。[验收证据与内容核对](docs/el-release-evidence.md)。

### 每日学习入口（#84）

选择今天可用时间后，首页“今天下一步”显示一个学习入口和一句推荐理由。
未完成的轮次优先继续；暂停、刷新后仍保留原卡序、目标与预算。
首页默认突出任务和开始按钮；在“计划详情与目标设置”中查看样本、估算依据与余量，或更改每日最低目标。
完成页显示真实已保存数量和仍需复习的词，明确今天可以结束；详细指标与额外测验按需展开。暂停不会显示本轮完成。
建议只参考本浏览器最近 30 轮：最近三轮有两轮中途退出，下一轮默认建议约三分钟；连续三轮完整保存后再按 3→8→15 分钟逐档恢复，最多到你选择的常规预算。你仍可显式改选时间；跳过不作为上调依据。暂停、刷新和重复确认不重复计轮，已开始的轮次不重算。
建议记录不进入 FSRS、完成统计或数据库备份；成功恢复备份后清除旧浏览器建议。浏览器存储不可用时仍可学习，但不记录这些观察；无法观察的直接关窗不推断为完成或退出。
定向验证：`npm --prefix frontend run test:e2e -- --ticket EL-22`；见 [验证记录](docs/verification/daily-learning-flow.md)。
